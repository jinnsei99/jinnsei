## 알려진 문제
- 작업 환경: 이 컴퓨터에 git이 없고, `maxb` 폴더는 git 저장소가 아니다. 커밋과 저장소 옮기기는 Git for Windows를 설치하거나, GitHub 저장소와 연결된 클라우드 세션에서 해야 한다.
- 자동 점검이 없다. 무엇을 고치면 어디가 깨지는지 사람이 눈으로 찾아야 한다(단계 0-C).
- 화면 조합이 많다: 디자인 A·B·C × 컴퓨터·아이패드 버전 + 좁은 화면. `app.css` 1,548줄에 `data-design` 선택자 약 117개, `.touch` 99개, `.narrow` 107개가 겹친다.
- 토큰 밖에 직접 쓴 값이 많다: 색 246개(`#…` 160 + `rgb(a)` 86), `font-size` 숫자 136개, `border-radius` 숫자 148개, `ui-*.js` 안의 색 글자 22개. 간격·글자 크기 토큰은 없다.
- 색 토큰이 `app.css`에 다섯 벌 복사돼 있어서, 색 하나를 바꾸려면 여러 곳을 고쳐야 한다.
- `manifest.webmanifest`의 `icons/maskable-512.png`가 `sw.js` `CORE`에 없다. 영향은 작다(오프라인일 때 설치 아이콘). 진짜 저장소에서 확인 필요.
- `js/samples.js`를 만드는 도구가 `ullim/` 안에 없다. 어디 있는지 확인 필요.
- Claude 아티팩트 판(README 맨 위 링크)을 올리는 방법이 어디에도 적혀 있지 않다.
- 이 문서들은 2026-11-09 23:20에 받은 `ullim/` 사본(아이콘·MP3·git 기록 없음)을 보고 썼다. 그 뒤에 저장소가 바뀌었으면 맞춰야 한다.
