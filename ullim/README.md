# 울림 스튜디오

Ableton Live 12처럼 쓰는 음악 작업 앱이에요. 브라우저에서 바로 돌아가고 빌드 과정이 없어요. 전자음악을 빨리 시작할 수 있게 장르 템플릿, 스텝 시퀀서, 씬으로 곡 만들기를 담았어요. 신스 말고도 피아노·기타·일렉 기타·베이스·현악·관악·오르간·콰이어·가야금 같은 진짜 악기 소리를 골라 쓰고, 기타 앰프와 밴드 드럼 킷으로 밴드 사운드도 만들어요. 쉬운 손잡이로 소리를 다듬어 **내 사운드**로 저장하고, 오디오는 **파형 편집** 창에서 직접 자르고 붙여요. 화면은 **디자인 세 가지**(A 컨트롤 룸 · B 스텝 가이드 · C 작업대) 중에서 골라 써요.

- **웹사이트**: https://jinnsei99.github.io/jinnsei/ullim/ — PC·아이패드·휴대폰에서 앱으로 설치할 수 있고, 한 번 열면 인터넷 없이도 열려요 (아래 '아이패드에서 쓰기', '웹사이트로 쓰기').
- Claude에서 바로 쓰기: https://claude.ai/artifact/Thx9zzCx7voyvXnDY7V5rN (프로젝트가 내 Claude 계정에 저장돼요)
- 이 폴더의 `index.html`을 크롬이나 엣지로 열어도 똑같이 쓸 수 있어요. 인터넷이 없어도 소리가 나요 (글꼴만 기본 글꼴로 바뀌어요).

처음 열면 시작 창이 떠요. **장르**(하우스 · 테크노 · 트랩 · 드럼 앤 베이스 · 로파이 힙합 · 재즈 힙합 · 록 밴드 · 팝 밴드 · 퓨처 베이스 · 샘플 플립)를 고르면 템포·키·드럼·베이스·코드·사이드체인과 인트로부터 아웃트로까지 곡 뼈대가 한 번에 만들어져요. **데모 곡 듣기**를 고르면 미리 만들어 둔 **새벽 네 시** (122 BPM, A 마이너)가 재생돼요. **P**를 누르면 패드 화면이 열리고, 로봇 보컬 찹을 Z·X·C·V, A·S·D·F … 글자 키로 두드릴 수 있어요.

## 화면

| 칸 | 하는 일 |
|---|---|
| 컨트롤 바 (위) | 템포·탭 템포·박자표, 메트로놈, 런치 퀀타이즈, 재생·정지·녹음·세션 녹음·MIDI 캡처, 재생 위치, 어레인지먼트로 돌아가기, 루프, 스윙, 프로젝트 키, 그리기·자동화 모드, 패드 화면, 컴퓨터 건반, MIDI 매핑 |
| 브라우저 (왼쪽) | 사운드, 드럼 키트, 루프 패드 키트, 악기, 오디오·MIDI 이펙트, 클립 템플릿, 샘플, 가져온 오디오, 저장된 프로젝트 |
| 세션 / 어레인지먼트 / 패드 (가운데) | 세션과 어레인지먼트는 Tab으로 오가고, 패드 화면은 P로 열고 닫아요 |
| 정보 창 (왼쪽 아래) | 마우스를 올린 버튼·노브의 이름과 설명, 노브의 지금 값 |
| 클립 / 장치 (아래) | 고른 클립의 스텝 시퀀서(드럼·패드)·피아노 롤·파형, 고른 트랙의 장치 체인. Shift+Tab으로 오가요 |

화면 폭이 860px보다 좁으면 (휴대폰, 세로로 든 아이패드, Claude 옆 창) 아래 탭으로 세션 · 어레인지 · 패드 · 편집 · 브라우저를 한 칸씩 봐요.

## 화면 디자인 고르기 (A · B · C)

같은 기능을 세 가지 배치로 써요. 아래 상태 줄의 **디자인** 단추, 메뉴 › **화면 디자인**(그림으로 보고 고르기도 있어요), 환경설정 중 어디서든 바꾸고, 새로 고침 없이 바로 바뀌어요. 고른 디자인과 마지막 단계·탭은 그 브라우저에 기억해요.

| 디자인 | 배치 | 이럴 때 좋아요 |
|---|---|---|
| **A · 컨트롤 룸** — 한 화면에 다 | 위쪽 **세션 · 곡 · 패드** 단추로 가운데를 바꾸고, 왼쪽 브라우저, 아래 클립·장치 칸, 오른쪽 **고른 트랙** 칸(소리 고르기 ◀ ▶, 소리 다듬기, 장치 순서와 켜기/끄기, 볼륨·팬·센드)이 늘 함께 보여요. 모서리가 각지고 촘촘해요 | 컴퓨터로 빠르게, 여러 칸을 한꺼번에 보며 작업할 때 |
| **B · 스텝 가이드** — 단계별로 | 위에 **1 만들기 → 2 소리 → 3 곡 짜기 → 4 믹스 → 5 내보내기**, 왼쪽에 트랙 목록(소리가 나면 막대가 움직여요), 아래에 크게 만든 재생 막대와 **이전 · 다음** 단추. 단계마다 제목과 한 줄 안내가 있고, 한 번에 한 가지만 크게 보여요. 둥글고 넉넉해요 | 처음 쓸 때, 아이패드에서 손가락으로 쓸 때 |
| **C · 작업대** — 곡 지도 + 단계 탭 | 위쪽 **곡 지도**(타임라인 ↔ 클립 런처)가 늘 보이고, 그 아래 **1 연주 · 2 소리 · 3 편집 · 4 믹스 · 5 내보내기** 탭이 아래 작업대를 바꿔요. 탭 줄 왼쪽에 고른 트랙이 늘 적혀 있어요 | 곡 전체를 보면서 한 트랙씩 다듬을 때 (컴퓨터·아이패드 모두) |

- **A의 설명 칸**: 컴퓨터 버전에서는 왼쪽 브라우저 아래에 마우스를 올린 곳을 설명해 주는 칸이 있어요. 브라우저와 설명 칸 사이 경계선을 끌면 설명 칸 높이만 바뀌고(아래 클립·장치 칸과 따로), 그만큼 브라우저가 늘거나 줄어요. 경계선을 두 번 누르면 접고 펴고, 경계선을 고른 뒤 ↑ ↓로도 조절해요. 높이는 이 기기에 기억돼요.
- **B 단계마다 보이는 것**: 1 만들기는 패드·건반(고른 트랙을 쳐요)과 **클립 편집**(스텝 시퀀서·피아노 롤), 2 소리는 브라우저 + 장치(소리 다듬기 포함), 3 곡 짜기는 씬(세션)이나 타임라인 + 아래 클립·장치 칸, 4 믹스는 모든 트랙의 큰 믹서, 5 내보내기는 WAV·스템·MIDI·프로젝트 파일.
- **C 탭마다 보이는 것**: 1 연주는 패드·건반, 2 소리는 브라우저 + 장치, 3 편집은 고른 클립, 4 믹스는 큰 믹서, 5 내보내기. 소리 탭을 보다가 곡 지도의 클립을 누르면 편집 탭으로 넘어가요. 곡 지도와 탭 줄 사이의 경계선을 끌면 곡 지도 높이가 바뀌어요. 곡 지도의 트랙 줄은 한눈에 들어오게 낮아요 (자동화 모드에서는 원래 높이).
- **단축키는 디자인에 맞게**: Tab은 A에서 세션 ↔ 곡, B에서 곡 짜기(씬 ↔ 타임라인), C에서 곡 지도(타임라인 ↔ 클립 런처). P는 A에서 패드 화면, B에서 1 만들기, C에서 1 연주 탭이고 한 번 더 누르면 앞 화면으로 돌아가요. Shift+Tab은 A·B에서 클립 ↔ 장치 칸, C에서 편집 ↔ 소리 탭.
- **화면 버전(컴퓨터 · 아이패드)과는 따로** 골라요. 버전은 버튼·칸의 크기, 디자인은 배치예요. 폭이 좁은 화면(휴대폰 등)에서는 어느 디자인을 골라도 위의 한 칸씩 화면을 쓰고, 넓어지면 고른 디자인으로 돌아와요.
- A의 오른쪽 칸은 × 단추나 상태 줄의 단추로 닫고 열어요. 직접 정하기 전에는 폭이 넓은 컴퓨터 화면(1360px 이상)에서만 열려 있고, 아이패드 버전이나 좁은 창에서는 세션 칸이 좁아지지 않게 닫힌 채로 시작해요. 닫으면 소리 다듬기는 아래 장치 칸 맨 앞에 다시 나와요.

## 아이패드에서 쓰기

사파리로 https://jinnsei99.github.io/jinnsei/ullim/ 을 열고 공유 › **홈 화면에 추가**를 하면 전체 화면 앱처럼 열려요. 가로로 들면 PC와 같은 화면(브라우저 · 세션/어레인지먼트 · 아래 편집 칸)이고, 세로로 들면 아래 탭으로 한 칸씩 봐요. 아이패드 버전에서는 버튼·칸·메뉴가 손가락 크기로 커지고, 마우스를 올려야 보이던 정보 칸은 빠져요.

**컴퓨터 버전 · 아이패드 버전 고르기** — 아래 상태 줄 오른쪽의 버튼(지금 버전 이름이 적혀 있어요), 메뉴 › 화면 버전, 환경설정 중 어디서든 골라요. 처음 열면 시작 창 아래에서도 골라요.

| 고르기 | 화면 |
|---|---|
| 자동 | 이 기기에 맞춰요. 아이패드·휴대폰은 아이패드 버전, 마우스를 쓰는 컴퓨터는 컴퓨터 버전 |
| 컴퓨터 버전 | 조절기를 작게 많이 보여 주고 정보 칸이 있어요. 세로로 든 아이패드에서도 컴퓨터와 같은 배치예요 (폭 600px보다 좁을 때만 아래 탭) |
| 아이패드 버전 | 버튼·칸·메뉴를 크게, 상태 줄에 되돌리기 버튼. 터치 화면 노트북이나 큰 화면 컴퓨터에서도 고를 수 있어요 |

- 고른 버전은 그 기기의 브라우저에 기억하고, 바꾸면 새로 고침 없이 바로 바뀌어요.
- 어느 버전이든 손가락 조작(길게 누르기, 두 번 탭, 두 손가락 밀기·벌리기)과 마우스·키보드는 그대로 돼요.

| 손가락 | 하는 일 |
|---|---|
| 탭 | 누르기·고르기. 브라우저 항목은 한 번 탭하면 미리 들어요 |
| 두 번 탭 | 더블클릭: 빈 칸에 클립 만들기, 피아노 롤에 음 넣기·지우기, 노브를 기본값으로, 브라우저 항목을 고른 트랙에 넣기, 이름 바꾸기 |
| 길게 누르기 | 오른쪽 클릭 메뉴: 클립·씬·트랙·음표·어레인지먼트 클립. 스텝 시퀀서의 찍힌 칸은 세기가 바뀌어요 |
| 두 손가락으로 밀기 | 피아노 롤·어레인지먼트·스텝 시퀀서·오디오 파형을 앞뒤·위아래로 넘겨요 |
| 두 손가락 벌리기·오므리기 | 확대·축소 (피아노 롤은 가로로 벌리면 시간, 세로로 벌리면 줄 높이) |
| 한 손가락으로 끌기 | 음·클립 옮기기와 길이 바꾸기, 노브·페이더 돌리기. 클립·음의 양 끝은 손가락에 맞게 넓게 잡혀요 |

- **패드 화면이 연주 화면**이에요 (가로: 위쪽 패드 아이콘, 세로: 아래 탭의 패드). 맨 왼쪽에서 칠 트랙을 고르면 그 악기 모양으로 바뀌어요: 드럼 머신은 **드럼 세트**, 기타·베이스는 **코드 줄과 지판**, 현악은 활로 켜는 지판, 하프·가야금은 줄, 마림바·칼림바·스틸 드럼·종은 그 악기, 루프 패드는 패드 16개, 신스·피아노는 **터치 건반**이에요 (아래 '악기별 연주 화면'). 트랙을 길게 눌러 "손가락으로 연주"를 골라도 돼요.
  - **건반**: 피아노 건반이 화면 폭에 맞춰 1~4옥타브, 세로 화면에서는 두 줄로 나와요. 키에 맞는 음에 점, 근음에 진한 점이 있어요.
  - **스케일**: 키에 맞는 음만 칸으로 늘어놓아요. 오른쪽으로 한 음씩, 위 줄은 4도 위라서 아무 칸이나 쳐도 어울려요. 근음 칸은 트랙 색이에요.
  - **코드**: 켜면 한 손가락으로 지금 키의 3화음을 쳐요. 스케일 칸에는 코드 이름(Am, C, Dm …)이 적혀요.
  - **코드 패드**: 지금 키의 주요 화음을 큰 버튼으로 늘어놓아요 (아래 '주요 화음 바로 쓰기').
  - 여러 손가락을 따로 울리고, 손가락을 미끄러뜨리면 지나가는 음을 차례로 쳐요. −/+로 옥타브, 세기 칸으로 세기를 바꿔요.
  - ●로 녹음 준비를 켜고 ● 녹음을 누르면 친 그대로 클립이 돼요. 패드도 같아요.
  - **연주 칸 크게** 버튼은 아래 편집 칸을 접어 패드와 건반을 크게 써요.
- 클립은 끌어서 옮기는 대신 길게 눌러 **복사**한 뒤, 빈 칸을 길게 눌러 **붙여넣기**해요. 패드 메뉴는 패드 옆 편집 칸의 ⋯ 버튼에 있어요 (패드를 길게 누르는 건 연주라서 메뉴가 뜨지 않아요).
- 상태 줄 오른쪽의 ↶ ↷ 버튼으로 되돌리기·다시 실행을 해요. 길게 누르면 되돌리기 기록이 열려 여러 단계를 한 번에 돌아가요.
- 위쪽 🔍 버튼(빠른 실행)으로 "녹음", "피아노", "템포 90"처럼 쳐서 바로 할 수 있어요. 키보드가 없을 때 메뉴를 뒤지지 않아도 돼요.
- 최신 아이패드OS의 사파리에서는 무음 모드여도 소리가 나요. 처음 소리가 안 나면 화면을 한 번 탭하거나 상태 줄의 "소리 켜기"를 눌러요.
- WAV·MIDI·프로젝트 파일을 내보내면, 사파리가 공유할 수 있는 파일은 "저장·공유" 버튼이 나와요. 공유 화면에서 "파일에 저장"을 고르면 파일 앱에 남고, AirDrop이나 다른 음악 앱으로 바로 보낼 수도 있어요. 오디오는 파일 앱에서 골라 가져와요.
- 마이크 녹음이 돼요. 아이패드의 브라우저는 MIDI 장치(Web MIDI)를 지원하지 않아서, MIDI 건반(SMK-25 mini · MPK mini MK3 등) 대신 연주 화면의 악기 모양 화면과 터치 건반으로 쳐요. MIDI 건반은 컴퓨터의 크롬·엣지에서 써요.
- 매직 키보드를 붙이면 단축키(⌘)가 그대로 돼요. 건반 화면에서는 A~K 줄이 건반, Z/X가 옥타브예요.
- 프로젝트는 그 기기의 사파리에 저장돼요. 홈 화면에 추가해 두면 오래 쓰지 않아도 지워지지 않아요. 따로 남겨 두려면 메뉴 › 프로젝트 파일 받기 › 공유 화면의 "파일에 저장"을 써요.

### 전자음악 빨리 시작하기
**장르로 시작** — 메뉴 › 새 프로젝트, 또는 브라우저 › 프로젝트 › 장르로 시작에서 골라요.

| 장르 | 템포 · 키 | 들어 있는 것 |
|---|---|---|
| 하우스 | 124 BPM · A 마이너 | 네 박 킥에 오프비트 하이햇, 펌핑하는 베이스와 건반 스탭 |
| 테크노 | 130 BPM · F 마이너 | 단단한 킥과 굴러가는 애시드 베이스, 짧은 신스 스탭 |
| 트랩 | 140 BPM · C 마이너 | 셋잇단 하이햇 롤, 미끄러지는 808 베이스, 어두운 벨 멜로디 |

| 팝 밴드 | 120 BPM · D 메이저 | 팝 드럼 킷과 탬버린, 핑거 베이스, 클린 기타 아르페지오·스트럼, 크런치 기타, 밴드 피아노 (D – A – Bm – G) |

| 샘플 플립 | 150 BPM · F 마이너 | 2000년대 가요 느낌의 샘플(D♭△7 – E♭7 – Cm7 – Fm7)을 훅에서는 통째로, 벌스에서는 한 박씩 잘라 순서를 바꿔 깔고(플립), 하프타임 트랩 드럼, 샘플 근음을 따라가는 디스토션 808, 거친 레이지 리드 |

- 장르 프로젝트에는 세션 뷰의 씬(인트로 · 빌드업 · 드롭 · 브레이크 · 아웃트로, 로파이·재즈 힙합은 인트로 · 메인 · 브레이크 · 아웃트로, 록 밴드는 인트로 · 벌스 · 코러스 · 기타 솔로 · 아웃트로, 팝 밴드는 인트로 · 벌스 · 프리코러스 · 코러스 · 브릿지 · 아웃트로, 샘플 플립은 인트로 · 훅 · 벌스 · 브레이크 · 아웃트로)과, 그 씬을 늘어놓은 어레인지먼트 곡이 함께 들어 있어요. 바로 Space로 처음부터 들을 수 있어요.
- 로파이·재즈 힙합·밴드를 뺀 다섯 장르는 빌드업에 점점 빨라지는 롤과 라이저가, 드롭 첫 박에 크래시와 임팩트가 들어가요. 라이저는 드롭 바로 앞에서 끝나요.
- 하우스·테크노·드럼 앤 베이스·퓨처 베이스는 베이스나 코드에 박마다 소리를 눌러 주는 **Ducker**(사이드체인 펌핑)가 걸려 있어요. 모든 장르의 마스터에는 리미터가 걸려 있어요.
- 트랙 소리 크기는 실제로 렌더해서 재 보고 맞췄어요. 마음에 안 드는 소리는 브라우저에서 다른 사운드를 트랙에 끌어다 놓으면 바뀌어요.

**샘플 플립** — 옛 노래의 한 부분을 잘라 순서를 바꾸고 새 드럼과 베이스 위에 올리는 힙합식 만들기예요 (예전 가요·힙합을 샘플링해 트랩 비트에 올리는 방식).
- 장르 **샘플 플립**을 고르면, 앱이 직접 만든 **옛 가요 샘플**(2000년대 가요 음반에서 딴 듯한 네 마디: 전자 피아노 화음 · 패드 · "오~ 아~" 노래 훅, 낮은·높은 소리를 깎고 LP 잡음을 얹음)로 시작해요. 실제 노래가 아니라 앱이 만든 소리라 마음껏 써도 돼요.
- **샘플 찹** 트랙은 루프 패드 키트 **옛 가요 샘플 찹**이에요. 샘플을 한 박씩 16조각으로 잘라 패드에 넣었고, 한 줄이 한 마디(D♭△7 · E♭7 · Cm7 · Fm7)예요. 줄 안에서 순서를 바꿔 치면 화음은 808과 맞고 리듬만 새로워져요. 새로 친 조각이 앞 조각을 끊어요(초크).
- **내 샘플로 바꾸기**: 패드 화면에서 내 오디오 파일을 파형에 끌어다 놓거나 샘플 메뉴의 "원본 샘플 바꾸기"를 고르면 바로 잘려 패드 1~16에 들어가요 (루프는 박자마다, 아니면 소리 시작점마다). 자르기 메뉴에서 소리 시작점 · 박자 · 같은 길이 16조각으로 다시 자를 수 있어요. 패드는 글자 키나 MIDI 건반 · MPK 패드로 쳐서 녹음해요.
- 다른 사람의 노래를 샘플로 쓰면 혼자 연습하는 건 괜찮지만, 곡을 공개하거나 팔려면 원곡 권리자의 허락(샘플 클리어런스)이 필요해요.
- **레이지 리드**: 다섯 겹으로 넓게 벌린 톱니파(유니즌)와 사각파를 세게 일그러뜨린 거친 리드예요. 사운드의 리드 묶음에도 있어요. 비슷한 소리는 아래 '레이지 · 트랩 소리'에 더 있어요.

**옛 가요 샘플 만들기** — 2000년대 가요 음반에서 딴 듯한 네 마디 루프를 직접 만들어요. 메뉴 › 옛 가요 샘플 만들기, 브라우저 › 샘플(또는 내 오디오) 맨 위, 패드 화면의 **샘플 ▾** › 옛 가요 샘플 만들어 넣기에서 열어요.

| 고르는 것 | 무엇이 있나 |
|---|---|
| 화음 진행 | 왕도 진행(Ⅳ – Ⅴ – ⅲ – ⅵ) · 발라드(Ⅰ – Ⅴ – ⅵ – Ⅳ) · 캐논(한 마디에 두 화음) · 알앤비(ⅱ – Ⅴ – Ⅰ – ⅵ) · 슬픈 마이너(ⅵ – Ⅳ – Ⅰ – Ⅴ) |
| 키 · 화음 | 메이저 키 12개, 3화음 · 7화음 · 9화음 |
| 건반 | 전자 피아노 · 로즈 · 그랜드 피아노(녹음 샘플) · 나일론 기타 · 비브라폰 |
| 바탕 | 없음 · 패드 · 현악 · 콰이어 |
| 반주 리듬 | 통통 튀게 · 두 번씩 · 길게 · 아르페지오 |
| 노래 훅 | 없음 · 오·아 · 오~ · 아~ · 우~, 목소리 맑게 · 보통 · 낮게, **멜로디 바꾸기**(같은 설정으로 다른 멜로디) |
| 옛 음반 느낌 | 0 ~ 100%: 낮은·높은 소리를 깎고, 살짝 일그러뜨리고, LP 잡음과 테이프 흔들림을 얹는 양 |

- 키는 프로젝트 키를 따라가요 (단조면 같은 음을 쓰는 나란한 메이저로, 예: F 마이너 → A♭ 메이저). 템포는 프로젝트 템포이고, 길이는 네 마디(16박)라서 한 박씩 자르면 찹 패드 16조각이 돼요. 템포가 다른 곡에 넣으면 템포에 맞춰 늘고 줄어요.
- 노래 훅은 센 박에서는 화음 음, 여린 박에서는 스케일 음을 골라 부르고, 마지막에 으뜸음으로 내려와요.
- **미리 듣기**를 켠 채로 고르면 조금 뒤 새 소리로 바뀌어요. **만들기**를 누르면 내 오디오에 루프로 저장되고, 새 오디오 트랙(고른 씬 줄)에 들어가요. 패드 화면에서 열었으면 그 트랙의 원본이 되어 바로 박자마다 잘려요.
- 어떤 건반을 골라도 같은 크기(RMS −15 dBFS, 봉우리 −1 dB 아래)로 만들어요.
- 만든 설정이 오디오와 함께 저장돼서, 내 오디오의 메뉴 › **옛 가요 샘플 고치기**로 다시 열어 바꿀 수 있어요. 프로젝트 파일에도 함께 담겨요.
- 모두 앱 안에서 계산한 소리라 마음껏 써도 돼요.

**스텝 시퀀서** — 드럼 머신·루프 패드 클립을 고르면 아래 칸이 스텝 시퀀서로 열려요 (위의 **스텝 / 피아노 롤**로 바꿔요).
- 줄은 패드 16개, 칸은 격자 한 칸이에요. 눌러서 찍고 다시 누르면 지워요. 끌면 여러 칸을 한 번에 찍거나 지워요.
- 오른쪽 버튼으로 누르면 세기가 100 → 127 → 64로 돌아요. 새로 찍는 칸의 세기도 위에서 골라요.
- 격자 1/8 · 1/16 · 1/32 · 1/16 셋잇단, 패턴 길이(늘리면 지금 패턴을 복제), **줄 채우기**(4분 · 2와 4 · 오프비트 · 8분 · 16분 · 줄 지우기), 모두 지우기.
- 줄 이름을 누르면 그 소리를 들어요. 재생 중에는 지금 칸이 밝게 지나가요.

**씬으로 곡 만들기** — 세션 뷰 오른쪽 아래의 **곡 만들기**, 메뉴, 씬 메뉴에서 열어요.
- 씬을 순서대로 골라 마디 수를 정하면 어레인지먼트에 한 번에 늘어놓아요. 루프 클립은 구간을 채우고, 라이저처럼 한 번 도는 클립은 구간 끝에 맞춰 드롭 직전에 끝나요.
- 곡 구조 고르기: 전자음악 기본(인트로 8 / 빌드업 8 / 드롭 16 / 브레이크 8 / 빌드업 8 / 드롭 16 / 아웃트로 8), 짧게(씬마다 4마디), 씬 순서대로(8마디씩). 씬 이름에 인트로·빌드·드롭 같은 말이 있으면 알아서 찾아요.
- 구간마다 위로 · 복제 · 빼기를 하고, 지금 어레인지먼트를 비울지 맨 뒤에 이어 붙일지 골라요.

**전자음악 사운드** — 리스 베이스, 808 베이스, 후버, 퓨처 베이스 코드(사이드체인 포함), 신스 스탭, 로파이 건반과 테크노(럼블 패드 포함) · 드럼 앤 베이스 드럼 키트를 더했어요. MIDI 도구에는 4분 → 8분 → 16분 → 32분으로 빨라지는 **빌드업 롤**이 생겼어요.

### 간편 기능

**빠른 실행** (Ctrl+K · ⌘K, 또는 위쪽 메뉴 버튼 옆의 🔍) — 하고 싶은 것을 글로 찾아 Enter로 바로 해요.
- 동작(재생 · 녹음 · 메트로놈 · 카운트인 · 루프 · 트랙 넣기 · 씬으로 곡 만들기 · 내보내기 · 환경설정 …), 화면(세션 · 곡 · 패드 · 디자인 A/B/C · 컴퓨터/아이패드 버전), 소리 80개, 드럼 킷, 루프 패드 키트, 이펙트, 장르 새 곡, 키(C 메이저 ~ B 마이너), 박자표, 트랙 고르기를 한 곳에서 찾아요.
- 이름 일부(`피아노`), 초성(`ㄱㄹㄷ` → 그랜드 피아노), 영어(`reverb`, `record`)로 찾아요. 숫자만 치면(`90`, `템포 90`) 그 템포로 바꾸는 줄이 맨 위에 나와요.
- 아무것도 안 치면 최근에 한 것(↺)과 자주 쓰는 동작이 나와요. ↑↓ 고르기, Enter 하기, Esc는 지우기 → 닫기. 소리는 고른 MIDI 트랙에 넣고(없으면 새 트랙), 켜고 끄는 것은 ✓·꺼짐으로 지금 상태를 보여 줘요.

**즐겨찾기 · 최근 쓴 소리** — 자주 쓰는 소리를 맨 위에 모아요.
- 브라우저 사운드 목록에서 줄에 마우스를 올리면 오른쪽에 ☆가 보여요. 누르면 **★ 즐겨찾기** 묶음에 들어가고, 다시 누르면 빠져요. 줄을 오른쪽 클릭(길게 누르기)하거나, 소리 고르기 창의 소리 버튼을 오른쪽 클릭(길게 누르기)해도 돼요.
- **최근 쓴 소리**에는 트랙에 넣은 소리 8개가 최근 것부터 모여요. 소리 고르기 창에서 이것저것 눌러 들어 본 소리는 빼고, 창을 닫을 때 남은 소리만 남겨요.
- 두 묶음은 브라우저와 소리 고르기 창 맨 위에 펼쳐져 있고, 별을 눌러 묶음이 바뀌어도 보던 줄이 제자리에 있어요. 검색할 때는 같은 소리가 두 번 나오지 않아요. 이 기기에 기억돼요.

**녹음 카운트인** — 멈춘 상태에서 녹음을 누르면 정한 마디만큼 딸깍 소리로 먼저 세고, 다음 마디 첫 박에 맞춰 재생과 녹음을 함께 시작해요.
- 메트로놈 버튼을 오른쪽 클릭(길게 누르기)해서 끄기 · 1마디 · 2마디 · 4마디를 골라요. 환경설정, 빠른 실행에서도 돼요. 켜 두면 메트로놈 버튼에 마디 수가 작게 떠요.
- 세는 동안 가운데에 박 숫자가 크게 뜨고, 누른 녹음 버튼이 깜빡여요. 메트로놈을 꺼 두어도 카운트인은 들려요. 6/8 같은 박자도 그 박자대로 세요.
- 숫자를 누르거나 Esc · Space · ■ · 녹음 버튼을 다시 누르면 그만둬요. 어레인지먼트 녹음과 세션 녹음 모두 되고, 이미 재생 중이면 세지 않고 바로 녹음해요.
- 마이크 녹음은 세는 동안 마이크를 미리 켜 두었다가, 센 부분을 잘라내고 1박부터 클립을 놓아요.

**되돌리기 기록** — 메뉴 › 되돌리기 기록, 또는 되돌리기 ↶ · 다시 실행 ↷ 버튼을 길게 누르거나 오른쪽 클릭하면 바꾼 것들이 최근 것부터 나와요(예: 템포 110 · 1번 전).
- 누르면 그때로 한 번에 돌아가요. 되돌린 것도 흐리게 남아 있어서 다시 눌러 돌아올 수 있어요. 새로 고치면 그 뒤의 되돌린 기록은 사라져요.

### 악기 고르기
진짜 악기 소리를 내는 장치 두 가지와 그 악기로 만든 사운드 79개가 있어서, 사운드는 모두 116개예요. 피아노, 현악 · 관악 · 색소폰, 교회 오르간, 하프 · 마림바 같은 말렛, 베이스 기타 · 업라이트 베이스, 재즈 · 일렉 기타, 우리처는 **녹음한 샘플**로 쳐요 (아래 '녹음 샘플').

| 장치 | 악기 (장치 안의 버튼으로 바꿔요) |
|---|---|
| **Acoustic** — 줄을 뜯거나 두드리는 악기 | 피아노: 그랜드 · 업라이트 · 펠트 / 일렉 피아노: 로즈 · 우리처 / 기타: 나일론 · 통기타 · 재즈 · 뮤트 / 일렉 기타: 일렉 · 싱글코일 · 험버커 · 팜 뮤트 · 리드 기타 / 베이스: 베이스 기타 · 피크 베이스 · 업라이트 베이스 / 줄 뜯기: 하프 · 가야금 · 피치카토 현 / 말렛·벨: 마림바 · 비브라폰 · 글로켄슈필 · 실로폰 · 오르골 · 칼림바 · 스틸 드럼 · 종 |
| **Ensemble** — 누르는 동안 이어지는 악기 | 현악: 현악 합주 · 바이올린 · 첼로 / 관악: 브라스 섹션 · 트럼펫 · 뮤트 트럼펫 · 플루겔혼 · 호른 · 트롬본 · 튜바 · 테너 색소폰 · 알토 색소폰 · 플루트 · 클라리넷 · 오보에 · 바순 / 목소리: 콰이어 아 · 우 / 오르간·리드: 재즈 · 록 · 교회 오르간 · 아코디언 · 하모니카 |

- **소리 고르기**: 아래 칸 머리줄(클립·장치 탭 옆)의 **소리** 버튼을 누르면 빈 샘플러를 뺀 사운드 115개가 피아노 · 키 · 기타 · 일렉 기타 · 밴드 · 베이스 · 현악 · 관악 · 말렛·벨 · 오르간 · 콰이어 · 월드 · 재즈 힙합 · 레이지 · 트랩 · 패드 · 코드 · 플럭 · 리드 · 보컬 · FX 묶음으로 열려요. 누를 때마다 그 트랙의 악기가 바뀌고 한 음 들려주며, 창은 닫을 때까지 열려 있어서 여러 소리를 이어서 들어 볼 수 있어요. **◀ ▶**는 창을 열지 않고 하나씩 넘겨요. 되돌리기로 앞 소리로 돌아가요.
- **묶음 열고 닫기**: 브라우저의 사운드 목록과 소리 고르기 창은 묶음 이름(피아노 · 키 · 기타 …, 옆의 숫자는 든 소리 개수)을 누르면 열리고 닫혀요.
  - 사운드 목록은 처음에 모두 접혀 있어서 묶음 이름만 보여요(내 사운드 · ★ 즐겨찾기 · 최근 쓴 소리만 펼쳐 있어요).
  - 소리 고르기 창은 지금 소리가 든 묶음만 펼쳐서 열려요.
  - **모두 펴기 · 모두 접기** 버튼이나 Alt+누르기로 한꺼번에 열고 닫아요.
  - 검색은 접힌 묶음 안까지 찾아요. 연 묶음은 이 기기에 기억돼요. 샘플·클립·이펙트 목록도 같은 방식이고, 처음에는 펼쳐 있어요.
- 패드 화면의 건반 줄에도 같은 소리 버튼과 ◀ ▶가 있어서, 아이패드로 건반을 치다가 바로 바꿀 수 있어요. 드럼·루프 패드 트랙은 장치의 ▾ 메뉴에서 키트를 바꿔요.
- **악기 안에서 고르기**: Acoustic·Ensemble 장치에는 악기 버튼이 있어요. 누르면 노브 설정은 그대로 둔 채 악기만 바뀌고 한 음 들려줘요. Tone(밝기) · Decay(울림 길이) · Body(몸통 울림) · Release, Ensemble은 Bright · Attack · Release · Vibrato · Ensemble(두께)로 다듬어요.
- 가야금은 뜯고 조금 뒤부터 음을 흔드는 농현이 들어가요. 하우스 피아노 · 로파이 피아노 · 크런치 기타처럼 이펙트까지 다듬은 사운드도 있어요. 예전 FM 마림바는 'FM 마림바'로 이름을 바꿨어요.
- 사운드를 바꾸면 그 사운드에 딸린 이펙트(리버브 등)도 함께 바뀌어요. 직접 넣은 이펙트는 그대로 남아요.

### 녹음 샘플
계산한 소리 대신 실제 악기를 녹음한 샘플로 치는 악기예요. 모두 무료로 공개된 녹음이에요 (아래 '소리 출처').

| 묶음 | 녹음으로 치는 악기 |
|---|---|
| 피아노 · 일렉 피아노 | 그랜드 피아노(Salamander, 세기 3칸) · 업라이트 피아노(세기 3칸) · **우리처**(Wurlitzer EP200, 세기 3칸) |
| 현악 | **현악 합주**(바이올린 · 비올라 · 첼로 섹션을 음역대로 겹쳐요) · **바이올린**(솔로) · **첼로**(첼로 섹션) · **피치카토 현**(바이올린 섹션, 낮은 음은 첼로 섹션, 세기 2칸) · 하프 |
| 금관 | **브라스 섹션**(트럼펫 · 호른 · 트롬본을 음역대로 겹쳐요) · **트럼펫** · **뮤트 트럼펫**(하몬 뮤트) · 새 **호른** · **트롬본** · **튜바** |
| 목관 · 색소폰 | **플루트** · **클라리넷** · 새 **오보에** · **바순** · **알토 색소폰** · **테너 색소폰** |
| 오르간 | **교회 오르간**(파이프 오르간, 낮은 음은 발건반) |
| 기타 · 베이스 | **재즈 기타**(아치톱 기타의 픽업 소리) · **일렉 기타**(앰프 없이 바로 녹음한 소리, 뒤의 Amp가 앰프 소리를 내요) · **베이스 기타**(재즈 베이스, 세기 2칸) · **업라이트 베이스**(더블 베이스 피치카토, 세기 2칸) |
| 말렛 | 마림바 · 글로켄슈필 · 실로폰 |

- **누르는 동안 이어지는 악기**(현악 · 관악 · 오르간)는 녹음에서 소리가 고른 구간을 찾아 루프를 만들어 두어서, 건반을 누르고 있는 만큼 끊김 없이 이어져요. 이음매는 파형이 가장 잘 맞는 자리에 부드럽게 겹쳐 넣었어요.
- 가장 가까운 음의 녹음을 그만큼 높이거나 낮춰서 치고, 녹음마다 실제 음높이를 재서 맞춰 두었어요 (이름과 실제 음이 한 옥타브 다른 녹음, 음이 살짝 높게 녹음된 색소폰도 바로잡았어요). 세기 칸마다 음역 전체가 고르게 들리도록 크기도 맞췄고, 예전 계산한 소리와 크기가 같아서 쓰던 프로젝트의 믹스가 그대로예요.
- 손잡이도 그대로 써요.
  - Acoustic: Tone(밝기) · Decay(길이) · Body(낮은 울림) · Release(건반을 뗄 때).
  - Ensemble: **Bright**는 0.5면 녹음 그대로, 내리면 어둡게, 올리면 밝게 · **Attack** 1이면 녹음된 어택 그대로(올리면 천천히 커지고, 내리면 어택 앞부분을 건너뛰어 더 빠르게) · **Release** · **Vibrato**는 녹음에 이미 떨림이 있어서 0.5를 넘긴 만큼 더 떨어요 · **Ensemble**은 섹션 악기(현악 합주 · 브라스 섹션 · 오르간)를 두 겹으로 좌우로 벌려 더 넓게.
  - 여리게 칠수록 조금 어둡게 나고, 피치 벤드 · 모듈레이션도 그대로 걸려요.
- 처음 쓸 때 받아서(악기 하나가 0.15~2.7 MB) 받는 동안에는 계산한 소리로 치고, 다 받으면 다음 음부터 녹음으로 쳐요. 받지 못하면(파일로 연 index.html 등) 계속 계산한 소리로 쳐요. 내보내기는 다 받은 뒤에 렌더해요.
- 새 소리: **호른 · 트롬본 · 튜바 · 오보에 · 바순**(관악 묶음), 랩 비트에 자주 쓰는 **트랩 플루트 · 다크 스트링 · 오케스트라 피치카토**(레이지 · 트랩 묶음).
- 재즈 힙합 · 밴드 · 샘플 플립 사운드 중 이 악기를 쓰는 소리(로파이 재즈 기타 · 붐뱁 업라이트 · 스모키 색소폰 · 딜레이 뮤트 트럼펫 · 로파이 플루트 · 먼지 낀 우리처 · 핑거 베이스 등)도 저절로 녹음으로 쳐요.

**녹음 드럼** — 진짜 드럼 키트를 녹음한 소리로 치는 킷이에요. 조각(킥 · 스네어 · 탐 · 하이햇 · 심벌)마다 **여리게 · 보통 · 세게 친 녹음**이 따로 있고, 같은 세기로 여러 번 쳐도 칠 때마다 **다른 녹음**(라운드 로빈 2~3개)이 나와서 기관총처럼 똑같이 반복되지 않아요.

| 킷 (브라우저 › 드럼) | 쓰는 녹음 |
|---|---|
| 록 드럼 | 1980년대의 큰 키트(24″ 킥, 탐 4개, 14″ 하이햇, 크래시 2개, 22″ 라이드와 벨) |
| 팝 드럼 · 빈티지 드럼 | 1970년대 키트(김정미 'Now'(1973)의 드럼 소리를 닮게 녹음한 키트)의 킥 · 스네어 · 탐 · 하이햇 + 록 키트의 심벌. 팝은 밝게, 빈티지는 어둡고 짧게 |
| 재즈 힙합 브러시 | 브러시로 친 스네어 · 스윕 · 탐 · 하이햇 · 라이드 · 크래시 + 70년대 키트의 킥 · 크로스 스틱 |
| 로파이 붐뱁 | 70년대 키트를 '레트로' 마이크(낮은 충실도)로 녹음한 소리 — 옛 가요 · 붐뱁 비트에 잘 어울려요 |

- 핸드 클랩 · 탬버린 · 손가락 스냅 · 셰이커 · 808 서브는 그대로 계산한 소리예요. 909 · 808 · 트랩 · 레이지 · 테크노 · 드럼 앤 베이스 킷도 원래 전자 드럼 머신 소리라 계산한 소리로 둬요.
- 패드의 **Tune**(반음) · **Decay**(0.5면 녹음 그대로, 내리면 짧게) · **Tone**(0.5면 그대로, 내리면 어둡게, 올리면 밝게) · Level · Pan · 초크가 녹음에도 그대로 걸려요.
- 드럼 머신 장치의 패드 소리에서 **녹음 드럼**을 고르면 네 키트의 조각 41가지 중에서 아무거나 패드에 넣을 수 있어요 (예: 록 킥 + 로파이 스네어).
- 크기는 패드마다 예전 계산한 드럼과 같게 맞췄어요 (가장 센 100 ms, 녹음 여러 개의 평균). 진짜 드럼은 앞소리가 더 뾰족해서, 세게 친 킥 · 스네어 · 림샷 · 탐은 앞소리를 살짝 둥글게 깎아 두었어요. 그래서 마스터 리미터가 없는 빈 프로젝트에서 세기 127로 쳐도 어느 패드든 -1.5 dBFS를 넘지 않고, 장르 템플릿의 마스터 리미터도 예전보다 더 일하지 않아요.
- 예전에 만든 프로젝트의 록 · 팝 · 빈티지 · 브러시 킷도 열 때 저절로 녹음 드럼으로 바뀌어요. 키트를 받기 전이나 받지 못하면 예전 계산한 드럼으로 쳐요.

### 녹음 · 합성 고르기
소리마다 **녹음**(실제 악기를 녹음한 샘플)인지 **합성**(녹음 없이 앱이 계산해서 만든 소리, 기계음)인지 보이고, 둘 다 되는 소리는 **악기마다** 어느 쪽으로 칠지 골라요.

- **소리 이름 옆:** 아래 칸 머리줄의 '소리 [악기 이름 ▾] ◀ ▶' 옆, 고른 트랙 칸의 '소리 방식', 연주 화면 도구 막대에 그 트랙 악기의 **녹음 | 합성**이 있어요. 누르면 바로 바꾸고 한 음 들려줘요.
- **둘 다 되는 소리 옆의 녹음 · 합성 단추:** 브라우저(전체로 볼 때)의 줄과 소리 고르기 창의 이름 옆에 붙어요. 누르면 그 소리를 그 방식으로 넣고, 지금 트랙에 든 소리면 지금 방식에 불이 들어와요. 예: 그랜드 피아노 옆의 합성을 누르면 계산한 그랜드 피아노가 들어가요.
- **장치 제목 줄:** Acoustic · Ensemble에 **녹음 | 합성** 단추가 있어요. 누르면 바로 바꿔요 (되돌리기도 돼요). 녹음이 없는 악기(펠트 피아노 · 로즈 · 콰이어 등)는 합성만 있어서 녹음이 흐리게 보여요. 고른 것은 악기 종류나 프리셋을 바꿔도 그대로이고 프로젝트에 저장돼요. 다른 악기 장치는 제목 줄에 **녹음** 또는 **합성** 꼬리표가 붙어요.
- **악기 버튼:** 녹음 샘플이 있는 악기에는 오른쪽 위에 **점(●)**이 있어요 (Acoustic 12가지, Ensemble 16가지).
- **브라우저(사운드 · 드럼)와 소리 고르기 창:** 위의 **전체 · 녹음 · 합성**으로 걸러요. 두 곳이 같은 설정을 써요.
  - 전체: 모든 소리. 둘 다 되는 소리는 옆의 녹음 · 합성 단추로 고르고, 그냥 두 번 눌러 넣으면 녹음으로 쳐요.
  - 녹음: 녹음 샘플로 치는 소리만.
  - 합성: 계산한 소리로 칠 수 있는 소리만. 녹음이 있는 악기도 여기서 고르면 계산한 소리로 넣어요.
  - 소리 고르기 창에서는 녹음으로 치는 소리에 점이 찍히고, ◀ ▶도 거른 소리 안에서만 넘어가요.
- **드럼 킷:** 녹음 킷마다 예전 합성 킷이 **(합성)**으로 바로 뒤에 있어요 (로파이 붐뱁 · 재즈 힙합 브러시 · 록 · 팝 · 빈티지). 드럼 머신 킷(909 · 808 · 트랩 · 레이지 · 테크노 · DnB)은 원래 합성이에요. 패드 하나씩은 패드 편집의 소리 칸(합성 드럼 · 녹음 드럼 · 샘플)에서 바꿔요.
- 브라우저 검색이나 빠른 실행(Ctrl+K)에서 '녹음' · '합성'으로 찾아도 돼요.

### 재즈 힙합 악기
재즈 힙합(로파이 재즈·붐뱁)에 자주 쓰는 악기 9가지와, 그 악기를 낡은 테이프·LP 느낌으로 다듬은 사운드, 브러시 드럼 키트가 있어요. 브라우저 검색에 **재즈**를 치면 한꺼번에 찾아요.

| 악기 | 어떤 소리 | 들어 있는 곳 |
|---|---|---|
| 로즈 피아노 | 종처럼 맑은 일렉 피아노. 세게 치면 소리가 으르렁거려요(바크) | 키 |
| 우리처 | 리드를 때리는 일렉 피아노. 로즈보다 콧소리가 섞이고 짧게 울려요 | 키 |
| 펠트 피아노 | 해머와 줄 사이에 펠트를 끼운 듯 먹먹하고 부드러운 피아노 | 피아노 |
| 재즈 기타 | 할로우 바디 · 넥 픽업 · 플랫 와운드 줄의 따뜻하고 짧은 기타 | 기타 |
| 업라이트 베이스 | 손가락으로 뜯는 콘트라베이스. 둥근 기본음, 지판에 부딪는 '퉁', 세게 뜯으면 살짝 높았다 내려앉는 음 | 베이스 |
| 뮤트 트럼펫 | 하몬 뮤트를 낀 듯 가늘고 콧소리 나는 트럼펫 | 관악 |
| 플루겔혼 | 트럼펫보다 어둡고 둥근 금관 | 관악 |
| 테너 · 알토 색소폰 | 숨소리가 섞인 리드 소리, 늦게 들어오는 비브라토 | 관악 |

- **재즈 힙합 묶음** (소리 고르기 창 · 브라우저): 로파이 로즈 · 페이저 로즈 · 먼지 낀 우리처 · 로파이 펠트 피아노 · 로파이 재즈 기타 · 붐뱁 업라이트 · 로파이 비브라폰 · 딜레이 뮤트 트럼펫 · 스모키 색소폰 · 로파이 플루트. 테이프가 늘어난 듯 흔들리는 음(코러스 비브라토), 비트를 줄인 먼지 낀 질감, 높은 소리를 깎은 EQ, 작은 방 리버브가 사운드마다 알맞게 걸려 있어요.
- **재즈 힙합 브러시 키트** (브라우저 › 드럼): 둥근 킥, 먼지 낀 스네어, 크로스 스틱(림), 브러시 탭, 브러시 스윕, 재즈 라이드, 손가락 스냅, 셰이커. 이제 브러시 소리는 실제로 브러시로 친 녹음이에요 (위 '녹음 드럼'). 드럼 머신의 패드 종류에도 **Brush** · **Brush Swish**가 더해졌어요.
- **LP 잡음** (브라우저 › 샘플 › 질감): **바이닐 노이즈**(쉬 소리 위에 지직거림, 가끔 큰 틱, 턴테이블 웅웅거림)와 **테이프 히스**(천천히 출렁이는 쉬 소리). 4마디 루프라 오디오 트랙에 놓으면 끝없이 이어지고, 템포에 맞춰 늘고 줄되 잘게 썰지 않아서 쉬 소리가 끊기지 않아요. 페이더를 -10 dB쯤으로 낮춰 깔면 돼요.
- **재즈 힙합 장르**: 새 프로젝트에서 고르면 위 악기들로 곡 뼈대(로즈 · 업라이트 베이스 · 브러시 드럼 · 뮤트 트럼펫 · LP 잡음)가 만들어져요.

### 일렉 기타 · 밴드 사운드
진짜 일렉 기타처럼 들리도록 줄 소리와 **기타 앰프**를 따로 만들고, 밴드에 필요한 베이스 · 건반 · **어쿠스틱 드럼 킷** · 리프 템플릿 · 밴드 장르를 더했어요.

**Amp** (오디오 이펙트) — 기타·베이스 앰프와 스피커 캐비닛이에요. 일렉 기타 사운드에는 이미 들어 있고, 브라우저 › 오디오 이펙트에서 끌어다 다른 트랙에도 넣어요.
- **모델 6가지**: Clean(깨끗하게, 세게 치면 살짝 거칠게) · Crunch(브리티시 크런치) · Blues(가운데를 밀어 주는 오버드라이브) · Lead(하드 록 하이게인) · Metal(단단하게 조인 게인, 가운데가 비어 있어요) · Bass(낮은 소리는 깨끗하게 두고 위만 거칠게).
- **노브**는 진짜 앰프처럼 0~10이에요: Gain(얼마나 일그러질지) · Bass · Mid · Treble · Presence. **Cabinet**: 4x12(크고 묵직) · 2x12(열린 콤보) · 1x12(작은 앰프, 가운데가 진함) · Bass 1x15 · Off(DI).
- 진공관처럼 비대칭으로 일그러지는 프리앰프 1~3단과 단 사이의 고역 필터, 톤 스택, 파워앰프, 스피커의 공진·급한 고역 감쇠까지 흉내 내서, 하이게인에서도 찢어지는 소리 대신 스피커로 듣는 소리가 나요.
- 모델과 Gain을 바꿔도 소리 크기가 크게 달라지지 않게 맞춰 두었어요(모든 모델·Gain에서 원래 기타 소리와 5 dB 안).
- 소리 다듬기 칸에 앰프가 있는 소리면 **드라이브** 손잡이가 생겨요(= 앰프 Gain).

**일렉 기타 줄 소리** (Acoustic 장치의 '일렉 기타' 줄): 일렉(녹음한 기타를 앰프 없이 받은 소리, '녹음 샘플') · **싱글코일**(맑고 쨍한 소리) · **험버커**(코일 두 개라 굵고 따뜻한 소리) · **팜 뮤트**(손날로 눌러 짧고 둔하게 끊기는 소리) · **리드 기타**(길게 끌면 손가락 비브라토). 베이스 줄에는 **피크 베이스**가 더해졌어요.
- 피크로 튕긴 줄 모양, 줄의 빠르기를 듣는 자석 픽업, 픽업 자리와 코일의 공진(싱글은 높고 뾰족하게, 험버커는 낮고 둥글게)을 계산해서, 앰프에 넣었을 때 진짜 기타처럼 들려요. 베이스와 팜 뮤트는 높은 배음이 진짜 줄처럼 빨리 사라져요. **일렉 기타** · **베이스 기타**는 이제 녹음 샘플로 치고, 받기 전에는 이 계산한 소리로 쳐요.

**일렉 기타 묶음** (사운드 11개): 클린 싱글코일 · 펑크 커팅 · 시티팝 클린 · 드림 팝 기타 · 크런치 브리티시 · 블루스 드라이브 · 하드 록 리듬 · 메탈 리듬 · 팜 뮤트 리프 · **파워 코드**(한 음만 쳐도 근음·5도·옥타브가 함께 울려요) · 록 리드. 브라우저에서 고르면 앰프까지 거친 소리로 미리 들려주고, 하이게인 소리는 파워 코드 리프로 들려줘요.

**밴드 묶음** (사운드 6개): 록 베이스(피크) · 핑거 베이스 · 그라인드 베이스(일그러진 베이스) · 밴드 피아노 · 밴드 오르간(앰프로 살짝 거칠게) · 밴드 로즈.

**밴드 드럼 킷** (브라우저 › 드럼): **록 드럼**(크고 울림 있게) · **팝 드럼**(단단하고 밝게) · **빈티지 드럼**(낮고 먹먹한 70년대 소리). 이제 실제 드럼 키트를 녹음한 소리로 쳐요 (위 '녹음 드럼'). 키트를 받기 전에는 가죽의 떨림과 채 소리, 스네어 철사줄, 심벌의 금속 배음을 계산한 소리로 쳐요.
- 패드 자리는 GM과 같아요: 킥 · 사이드 스틱 · 스네어 · 핸드 클랩 · 림샷 · 플로어 탐 · 하이햇 · 로우 탐 · 페달 햇 · 하이 탐 · 열린 햇 · 라이드 벨 · 탬버린 · 크래시 · 크래시 2 · 라이드. 닫힌 햇 · 페달 햇 · 열린 햇은 서로 끊어 줘요(초크).
- 드럼 머신의 패드 종류에도 어쿠스틱 소리 12가지(Kick · Snare · Rimshot · Side Stick · Tom · Hi-Hat · Pedal Hat · Open Hi-Hat · Crash · Ride · Ride Bell · Tambourine)가 더해졌어요.

**클립 템플릿** (브라우저 › 클립): 드럼에 록 8비트 · 팝 록(라이드) · 하프타임 록 · 펑크 록 질주 · 디스코·팝 펑크 · 모타운 4비트 · 발라드(사이드 스틱) · 셔플 블루스 · 록 필인(탐 돌리기), 새 **기타** 묶음에 파워 코드 8분 · 팜 뮤트 질주 · 스트러밍(다운·업) · 클린 아르페지오. 기타 템플릿은 키를 따라 기타처럼 짚고(E·A 모양 바레, 파워 코드), 스트럼은 다운은 낮은 줄부터·업은 높은 줄부터 조금씩 늦게 긁어요.

**밴드 장르** (새 프로젝트): **록 밴드**와 **팝 밴드**. 록 밴드는 벌스에 팜 뮤트, 코러스에 두 번 녹음한 듯 좌우로 벌린 기타, 기타 솔로까지 들어 있어요(위 장르 표).

### 레이지 · 트랩 소리
요즘 레이지(rage) · 트랩 비트에 자주 나오는, 넓게 퍼지는 신스와 일그러진 808 소리예요. 소리 고르기 창과 브라우저의 **레이지 · 트랩** 묶음(재즈 힙합 다음)에 있고, 검색에 **레이지**를 치면 한꺼번에 찾아요.

| 사운드 | 어떤 소리 | 이렇게 써요 |
|---|---|---|
| 레이지 슈퍼쏘우 | 톱니파 7겹을 좌우로 넓게 벌린 밝은 슈퍼쏘우 | 짧게 반복하는 리드 리프 |
| 하이프 키 | 사각파·톱니파를 거칠게 일그러뜨린 신스 키 | 엇박 코드 스탭 |
| 사이렌 리드 | 음 사이를 미끄러지고 빠르게 떨리는 모노 리드 | 길게 끄는 훅 |
| 하이퍼 플럭 | 위에서 "뾱" 떨어지는 짧은 유니즌 플럭 | 8분 아르페지오 |
| 플럭 벨 | 맑고 짧게 울리는 벨, 8분 점음표 딜레이 | 인트로 멜로디 |
| 브라스 스탭 | 필터가 확 열렸다 닫히는 짧은 금관 스탭 | 강조하는 코드 |
| 다크 패드 | 어둡고 넓게 퍼지며 천천히 숨 쉬는 패드 | 밑에 까는 화음 |
| 디스토션 808 | 한 옥타브 위에서 꽂히는 펀치에 세게 일그러뜨린 808 (모노 · 글라이드) | 킥과 같이 치는 베이스 |
| 글라이드 808 | 길게 울리고 음 사이를 천천히 미끄러지는 808 | 미끄러지는 베이스 줄 |

- **Poly Synth의 새 노브** (장치의 **Unison · Pitch** 칸):
  - **Unison** (1~7): 한 음에 살짝 어긋난 소리를 몇 겹 쌓을지. 겹친 소리들은 위상을 흩어서 출발해 짧은 음도 처음부터 넓게 들리고, 겹을 늘려도 소리 크기는 거의 그대로예요.
  - **Spread** (센트) · **Width**: 겹친 소리끼리 음을 얼마나 어긋나게 할지, 좌우로 얼마나 벌릴지. Width 0이면 가운데에 모인 채 두꺼워져요. Unison이 2 이상일 때만 보여요.
  - **Pitch Env** (±24반음) · **Pitch Time**: 음이 시작될 때 이만큼 높은(또는 낮은) 데서 출발해 Pitch Time 동안 제 음으로 돌아와요. 808의 펀치, 플럭의 "뾱" 소리에 써요. Pitch Time은 Pitch Env가 0이 아닐 때만 보여요.
  - 누르고 있는 음에도 Spread · Detune · Level · Wave가 바로 바뀌고, Unison 수는 다음 음부터 바뀌어요. 예전 프로젝트의 Poly Synth는 Unison 1 · Pitch Env 0으로 열려서 소리가 그대로예요.
- **레이지 드럼 키트** (브라우저 › 드럼, 트랩 다음): 단단하게 때리는 킥, 밝게 터지는 스네어·클랩, 트랩 키트보다 짧고 날카로운 하이햇, 길게 우는 808 서브.
- **샘플 플립** 장르의 808 트랙은 **디스토션 808**로, **레이지 리드**는 5겹 유니즌으로 더 넓어졌어요.
- 소리 크기는 비슷한 예전 사운드(슈퍼 쏘우 리드 · 플럭 · 벨 · 신스 스탭 · 808 베이스 · 따뜻한 패드)와 실제로 렌더해 재서 맞췄어요.
- 브라우저 미리 듣기는 소리의 쓰임대로 들려줘요: 808은 낮은 베이스 줄, 리드·플럭은 멜로디, 키·패드·벨은 화음. 이 소리로 저장한 내 사운드도 쓰임(예: 베이스)을 기억해요.

### 주요 화음 바로 쓰기
지금 키(상단 바의 키)에 맞는 화음을 버튼 하나로 치거나 클립에 넣어요. 키를 바꾸면 버튼도 따라 바뀌어요.

- **어떤 화음이 나오나**: 위 줄은 키 안의 화음 일곱 개(Ⅰ~Ⅶ)예요. A 마이너면 Am · B° · C · Dm · Em · F · G예요. 주요 3화음(Ⅰ · Ⅳ · Ⅴ, 단조는 i · iv · v)에는 '주요' 표시가 있어요. 아래 줄은 다음 화음으로 끌어가는 **세컨더리 도미넌트**예요(E → Am, A → Dm …). 알앤비·재즈에서 자주 써요.
- **종류**: 3화음 · 7화음(Am7, Cmaj7, G7 …) · 9화음(근음은 아래에 두고 위 네 음을 붙여 짚는 풍성한 소리)을 골라요.
- **부드럽게**: 켜면 앞 화음에서 손가락을 덜 움직이는 자리(자리바꿈)로 짚어서 화음이 매끄럽게 이어져요. **베이스**: 켜면 화음 아래 한 옥타브에 근음을 더해요.
- **패드 화면의 코드 패드**: 신스·샘플러 트랙의 건반 줄에서 **코드 패드**를 골라요. 누르면 화음이 통째로 울리고, 컴퓨터 키보드 1~7(아래 줄은 Q~Y)로도 쳐요. ● 녹음 준비를 켜고 녹음하면 친 그대로 클립이 돼요. 아이패드에서는 손가락 크기로 커져요.
  - **MIDI 건반으로 코드 패드**: 코드 패드를 열어 두면 MPK mini 같은 건반이 화음을 쳐요. 누른 건반의 음이 근음인 화음이 누르고 있는 동안 울리고(서스테인 페달을 밟으면 뗄 때까지), 맨 왼쪽 C부터 12건반(C2~B2)은 위 줄(키 안의 화음: C · Dm · Em …), 그 위 12건반(C3~B3)은 아래 줄(세컨더리 도미넌트: A → Dm 처럼, 없는 근음은 키 안의 화음)이에요. 키 밖의 음은 ♭II · ♭III · ♭VI 같은 장3화음(7화음이면 maj7)이고, 화음 종류 · 부드럽게 · 베이스 설정과 누른 세기를 그대로 따라요.
- **클립 칸의 코드 넣기**: MIDI 클립을 열고 **코드** 탭에서 화음 버튼을 누르면 '넣을 자리'에 화음이 들어가고 다음 자리로 넘어가요. Dm → G → C → Am 처럼 차례로 누르면 코드 진행이 되고, 클립이 짧으면 저절로 늘어나요. 한 화음 길이(1박 · 2박 · 1마디 · 2마디), **처음으로**, **덮어쓰기**(켜면 그 자리의 음을 새 화음으로 바꿔요)를 골라요. 넣을 자리는 피아노 롤에 주황 세로 줄로 보이고, 되돌리기로 하나씩 지워요. 드럼 클립에는 없어요.
- 펜타토닉·블루스처럼 일곱 음이 아닌 스케일은 가까운 메이저·마이너로 화음을 쌓아요.

### 소리 다듬기 · 내 사운드
악기가 있는 트랙의 장치 칸 맨 앞에 **소리 다듬기** 칸이 있어요. 악기마다 이름이 다른 노브를 몰라도, 쉬운 손잡이 몇 개로 소리를 바꿔요.

| 손잡이 | 하는 일 | 움직이는 노브 |
|---|---|---|
| 밝기 | 밝고 또렷하게 ↔ 어둡고 부드럽게 | 필터 Cutoff (샘플러는 필터를 켜고 끄기까지), Acoustic Tone, Ensemble Bright |
| 길이 | 소리가 남는 길이 | 엔벌로프 Decay·Release, Acoustic Decay·Release |
| 두께 | 여러 소리가 겹친 듯 두껍고 넓게 | Poly Synth 오실레이터 두 개를 반대로 어긋나게(±30센트), Ensemble 두께, Acoustic Body |
| 공간 | 리버브의 양 (끝까지 올리면 Dry/Wet 60%) | 악기 뒤의 리버브. 없으면 하나 넣어요 |
| 세기 반응 | 세게 칠수록 크게 나는 정도 | Velocity |
| 음량 | 악기 자체의 음량 (트랙 페이더와 따로) | Volume |

- 끄는 동안 소리가 바로 따라오고, 오른쪽 장치의 노브도 함께 움직여요. 손을 떼면 되돌리기 한 칸이에요. 화살표 키로도 5%씩 움직여요.
- 그 악기에 없는 손잡이는 보이지 않아요 (예: 드럼 머신은 공간·음량만).
- **처음 값으로**: 그 사운드를 처음 불러왔을 때의 노브 값으로 돌아가요.
- **내 사운드로 저장**: 지금 소리를 이름 붙여 저장해요. 악기와 함께 그 앞의 켜진 MIDI 이펙트(아르페지에이터 등), 뒤의 켜진 오디오 이펙트까지 한 묶음으로 담아요. 장치의 ▾ 메뉴와 소리 고르기 창 맨 위의 **지금 소리를 내 사운드로 저장**도 같아요.
- 저장한 소리는 소리 고르기 창과 브라우저 › 사운드의 맨 앞 **내 사운드** 묶음에 있어요. 어느 프로젝트에서나 불러오고, 오른쪽 클릭(길게 누르기)으로 이름을 바꾸거나 지워요. 지워도 이미 그 소리를 쓰는 트랙은 그대로예요.
- 같은 이름으로 저장하면 바꿀지 물어봐요. 내장 사운드와 같은 이름이면 뒤에 숫자를 붙여요.

### 파형 편집
오디오를 직접 자르고 붙이는 편집 창이에요. 이렇게 열어요.
- 오디오 클립: 클립 뷰 파형 위의 **파형 편집** 버튼, 또는 오디오 탭의 **파형 편집…**
- 샘플러: 장치의 **편집** 버튼 / 드럼 머신: 샘플을 넣은 패드의 **편집** 버튼
- 루프 패드: 패드 화면의 파형 옆 **파형 편집** (그 패드의 구간만 열어요)
- 브라우저의 샘플과 가져온 오디오: 오른쪽 클릭(길게 누르기) › **파형 편집…**

| 묶음 | 버튼 |
|---|---|
| 편집 | 잘라내기 · 복사 · 붙여넣기 · 지우기(뒤를 당겨요) · 무음(길이는 그대로) · 선택만 남기기 |
| 다듬기 | 페이드 인 · 페이드 아웃 · 소리 작게/크게(3 dB씩) · 노멀라이즈(-0.3 dB) · 거꾸로 |

- 파형을 끌어 구간을 고르고, 누르면 커서를 놓아요. 구간 양 끝을 끌어 넓히거나 좁히고, 두 번 누르면 전체를 골라요. 휠로 앞뒤로 넘기고 Ctrl+휠로 확대해요 (아이패드: 두 손가락으로 밀고 벌려요).
- 편집 창 안에서 Space 재생·정지, Ctrl+X / C / V 잘라내기·복사·붙여넣기, Delete 지우기, Ctrl+A 전체 선택, Ctrl+Z / Ctrl+Shift+Z 되돌리기·다시 실행. 복사한 소리는 다른 오디오의 편집 창에도 붙여 넣을 수 있어요.
- **저장**하면 원본은 그대로 두고 '이름 (편집)'이라는 새 오디오가 브라우저 › 가져온 오디오에 생기고, 연 곳(클립·샘플러·패드)이 새 오디오를 써요. 앱의 되돌리기 한 번이면 원래 소리로 돌아가요.
- 클립의 길이와 루프는 편집한 길이에 맞춰 따라가요. 저장하지 않고 닫으려 하면 버릴지 먼저 물어봐요.

### 세션 뷰
- 트랙마다 클립 칸이 있고, 가로 한 줄이 **씬**이에요. 클립의 ▶는 클립 하나, 오른쪽 열의 ▶는 씬 전체를 띄워요. 빈 칸인 트랙은 멈춰요.
- **런치 퀀타이즈**(없음~8마디)에 맞춰 다음 경계에서 시작해요. 기다리는 클립은 깜빡여요. 클립마다 퀀타이즈를 따로 정할 수 있어요.
- 런치 방식 Trigger · Gate · Toggle, **레가토**(앞 클립 위치에서 이어 받기), **팔로우 액션**(정해 둔 시간이 지나면 다음·이전·처음·마지막·아무거나·다른 것·다시·정지, A/B 확률).
- 씬 이름·씬 템포, 씬 넣기·복제·지우기, 재생 중인 클립으로 새 씬 만들기.
- 클립을 끌어 옮기고 Alt를 누르고 끌면 복사해요. 빈 칸을 두 번 누르면 빈 MIDI 클립이 생겨요.
- 아래 **믹서**: 센드 A/B…, 팬, 볼륨 페이더와 스테레오 미터(피크 홀드), 트랙 켜기/끄기, 솔로(Ctrl을 누르면 여러 개), 녹음 준비.
- 세션 클립을 띄운 트랙은 어레인지먼트를 잠시 쉬어요. **어레인지먼트로 돌아가기** 버튼이 켜지면 눌러서 되돌려요 (Live와 같은 동작).

### 어레인지먼트 뷰
- 눈금자를 눌러 시작 위치를 정하고, 위쪽 띠에서 **루프 구간**을 끌어 정해요. 재생 중에 루프를 켜고 끄거나 옮겨도 위치가 끊기지 않아요.
- 클립 옮기기(다른 트랙으로도), 양 끝 끌어 자르기·늘이기(루프 클립은 반복해서 늘어나요), Alt로 복사, Ctrl+D 복제, Ctrl+E 나누기, Ctrl+J 합치기, Ctrl+L 선택 구간을 루프로.
- 빈 MIDI 레인을 두 번 누르면 1마디 클립이 생겨요. 세션 클립이나 브라우저 항목을 끌어다 놓아도 돼요.
- **자동화 모드**(A): 레인마다 볼륨·팬·센드·장치 파라미터 중 하나를 골라 점을 찍고 끌어요. 점을 두 번 누르면 지워요. 그리기 모드(B)에서는 끄는 대로 격자마다 점을 찍어요. 재생하면 노브와 페이더가 자동화를 따라 움직여요.
- 따라가기, 확대(+/−, Ctrl+휠), 전체 보기, 스냅(Ctrl+4, Alt로 잠깐 반대).

### 루프 패드 · 패드 화면
MPC 같은 패드 16개(4×4)로 샘플 조각(찹)과 루프를 손가락과 키보드로 두드려요. 보컬을 잘게 잘라 패드로 치는 방식이에요.
- **루프 패드 악기**: 패드마다 원본 샘플의 한 구간이나 자기 샘플을 하나씩 가져요. C1부터 반음씩 패드 1~16이라 클립에 음표로 찍어도 돼요.
- **치는 방식**: 원샷(끝까지) · 누르는 동안 · 누르는 동안 반복 · 켜고 끄기(한 번 치면 계속, 다시 치면 멈춤). 같은 패드끼리, 같은 **초크 그룹**끼리는 서로 끊어요.
- **템포 맞춤**: 켜면 구간을 정한 박 수에 맞춰 16분음표 조각으로 이어 붙여서, 템포를 바꿔도 음높이가 그대로예요. 반복 패드는 **Launch** 값(1/16~1마디)만큼 박자 경계를 기다려 시작하고, 멈춰 있을 때는 이미 도는 루프에 맞춰요.
- **패드마다 글자 키**: 패드에 큰 글자로 적혀 있어요. 기본은 키보드 왼쪽 네 줄을 패드 모양 그대로 쓴 `1 2 3 4 / Q W E R / A S D F / Z X C V`(아래 줄이 패드 1~4). **키 지정**을 켜고 패드를 누른 뒤 원하는 글자를 누르면 바뀌고, 다음 패드로 넘어가요. 다른 패드가 쓰던 글자면 서로 바꿔요. **키 배치**에서 오른손 4×4, 두 줄 배치로 한꺼번에 바꿀 수도 있어요. 키는 자판 위치(`KeyboardEvent.code`)로 알아들어서 한글 입력 상태여도 돼요.
- 패드 화면에서는 그 트랙의 글자 키가 바로 패드예요. 다른 화면에서도 컴퓨터 건반(M)을 켜 두면 드럼 · 루프 패드 트랙은 패드 글자로 쳐요 (드럼 기본 배치: 1234 · QWER · ASDF · ZXCV). MIDI 패드는 C1~D#2가 패드 1~16이고, MIDI 건반은 맨 왼쪽 C부터 건반 하나가 패드 하나예요 (아래 'MIDI 건반').
- **노트 리피트**: 켜거나 Shift를 누른 채 치면, 누르는 동안 1/4~1/32(셋잇단 포함)마다 다시 쳐요. 재생 중이면 박자선에 맞고, 녹음하면 음표로 남아요.
- **편집**: 파형의 S·E 손잡이를 끌거나 빈 곳을 끌어 구간을 고르고, 음높이·게인·팬·거꾸로를 바꿔요. 원본 샘플을 **자르기**: 소리 시작점마다(자동), 박자마다, 같은 길이 16·8·4조각. 브라우저의 샘플을 파형에 놓으면 원본을 바꾸고 자동으로 자르고, 패드에 놓으면 그 패드만의 샘플이 돼요(루프면 켜고 끄는 템포 맞춤 패드로).
- **키트**: 로봇 보컬 찹(기계 목소리 16음절), 브레이크 찹(브레이크 두 마디를 16조각), 루프 팩(원샷 8개 + 템포에 맞는 루프 8개). 드럼 머신 트랙도 패드 화면에서 글자 키로 칠 수 있어요.
- 패드 화면의 ●로 녹음 준비를 하고 F9(어레인지먼트)나 세션 녹음을 누르면 친 그대로 클립이 돼요. "모두 멈춤"은 울리는 패드와 반복을 한 번에 멈추고, 트랜스포트를 멈춰도 반복 패드는 멈춰요.
- 패드 화면에서 신스·샘플러 트랙을 고르면 **터치 건반**이 나와요: 피아노 건반, 키에 맞는 음만 늘어놓은 스케일 칸, 한 손가락 코드 (위 '아이패드에서 쓰기').

### 악기별 연주 화면
개러지밴드의 터치 악기처럼, 패드 화면(P)은 고른 트랙의 악기 모양으로 나와요. 도구 막대의 화면 버튼으로 바꾸고(악기마다 따로 기억해요), 어느 악기든 **건반**으로도 칠 수 있어요. 여러 손가락이 따로 울리고, ● 녹음 준비를 켜고 녹음하면 친 그대로(스트럼의 줄 간격까지) 클립이 돼요.

| 악기 | 화면 |
|---|---|
| 드럼 머신 | **드럼** (드럼 세트) · 패드 |
| 기타 · 일렉 기타 | **코드** (코드 줄) · 지판 · 건반 |
| 베이스 | **코드** (근음 줄) · 지판 · 건반 |
| 현악 합주 · 피치카토 | **코드** (활로 켜는 합주) · 지판 · 건반 |
| 바이올린 · 첼로 | **지판** (프렛 없음) · 건반 |
| 하프 · 가야금 | **하프 / 가야금** (줄) · 건반 |
| 마림바 · 비브라폰 · 글로켄슈필 · 오르골 · 칼림바 · 스틸 드럼 · 종 | **악기** (그 악기 모양) · 건반 |
| 루프 패드 | 패드 |
| 피아노 · 일렉 피아노 · 오르간 · 관악 · 콰이어 · 신스 · 샘플러 | 건반 · 스케일 · 코드 패드 |

- **드럼 세트**: 킥 · 스네어 · 하이햇 · 페달 햇 · 탐 1 · 탐 2 · 플로어 탐 · 크래시 · 크래시 2 · 라이드가 진짜 드럼처럼 놓여 있어요. 패드 종류를 보고 자리를 찾아 앉혀서 밴드 킷도 전자 드럼 킷도 그대로 쳐요(없는 자리는 숨겨요). 자리를 못 찾은 패드(핸드 클랩 · 탬버린 · 808 서브 …)는 옆의 **퍼커션** 단추로 나와요.
  - 스네어 가운데는 스네어, **쇠 테두리는 사이드 스틱**. 하이햇 안쪽은 닫힌 햇, **점선 바깥 가장자리는 열린 햇**(닫힌 햇을 치면 멎어요). 라이드 넓은 면은 라이드, **가운데 벨은 라이드 벨**.
  - 북은 가운데를 칠수록 세게 울려요. 글자 키·노트 리피트·키 지정은 패드 화면과 같고, 글자 키로 치거나 재생 중인 클립이 치면 그 드럼이 번쩍여요. 화면 비율에 맞춰 가로 · 세로 · 납작한 배치로 바뀌어요.
- **기타 코드 줄**: 지금 키의 화음(일곱 개 + 장조는 ♭VII, 단조는 V)이 세로 줄로 늘어서고, 위가 가장 낮은 줄인 기타 여섯 줄이 가로질러요. 화음은 진짜 기타처럼 짚어요(열린 코드, F·B♭ 같은 바레, 막는 줄은 ×).
  - **코드 이름을 누르면** 낮은 줄부터 11ms씩 긁고(다운 스트럼), **줄 위를 위아래로 쓸면** 지나가는 줄이 차례로 울려요. 빠르게 쓸수록 세게, 아래에서 위로 쓸면 업 스트럼이에요. 한 줄만 누르면 그 줄만 (아르페지오).
  - 뜯은 줄은 손을 떼도 울리고, 같은 줄을 다시 뜯거나 다른 코드를 치면 바뀌어요. 키보드 1~8은 코드, Shift를 누르면 업 스트럼이에요. 화면이 좁으면 자주 쓰는 화음부터 남겨요.
  - **MIDI 건반으로 코드**: 이 화면을 열어 두면 MPK mini 같은 건반이 코드를 긁어요. 누른 건반의 음이 근음인 코드(G를 누르면 G, A를 누르면 Am, 화면이 좁아 안 보이는 줄도)이고, 키 밖의 음은 ♭II · ♭III · ♭VI 같은 장3화음이에요. 맨 왼쪽 C부터 12건반(25건반이면 C2~B2)은 다운, 그 위 12건반(C3~B3)은 업 스트럼이라 두 손으로 다운 · 업을 번갈아 쳐요. 세기는 누른 대로, 녹음하면 긁은 줄이 그대로 남아요. MIDI 장치 창의 건반 그림에 건반마다 코드 이름이 적혀요(↑ = 업).
- **지판**: 진짜 지판처럼 프렛 · 너트 · 자리 표시 점이 있고, 줄과 프렛을 눌러 한 음씩 쳐요. 키에 맞는 자리는 점, 으뜸음은 색 점(**음 이름**을 켜면 모두 이름). 같은 줄에서 미끄러지면 슬라이드, 줄을 가로질러 쓸면 그 프렛에서 긁어요. ◀ ▶로 넥을 따라 자리를 옮기고, 컴퓨터 건반 A~K로도 쳐요.
- **베이스**: 지판은 E A D G 네 줄. 코드 줄은 줄마다 근음 · 5도 · 옥타브 · 3도라서 코드 이름을 누르면 근음, 줄을 골라 치면 워킹 베이스가 돼요. MIDI 건반은 누른 음 코드의 근음(위 옥타브는 한 옥타브 위)을 쳐요.
- **현악**: 활로 켜는 악기라 누르고 있는 동안 소리가 이어지고(줄이 떨려요), 떼면 멈춰요. 합주의 코드 줄은 첼로 · 비올라 · 제2 · 제1 바이올린이 한 화음을 나눠 켜고(MIDI 건반도 누르고 있는 동안 그 코드를 켜요), 지판은 프렛 없는 지판(첼로 · 비올라 · 바이올린을 골라요)에서 미끄러뜨리면 음이 따라가요.
- **하프**: 키의 음계로 맞춘 줄이 백조 목 모양 틀에 매달려 있어요(빨간 줄이 으뜸음). 줄을 가로로 쓸면 글리산도. **가야금**: 안족이 비스듬히 놓인 열두 줄을 키의 5음 음계로 맞췄어요. 위아래로 쓸어 보세요. 키보드 A~; · Q~P로도 줄을 뜯어요.
- **말렛 · 벨**: 마림바(나무) · 비브라폰 · 글로켄슈필 · 오르골은 건반처럼 두 줄로 놓인 음판, **종**은 매달린 튜블러 벨, **칼림바**는 가운데가 가장 낮고 좌우로 번갈아 올라가는 건, **스틸 드럼**은 같은 음 이름이 한 방향에 모이고 둘레가 5도씩 도는 팬이에요. 음판 가운데를 칠수록 세게, 미끄러뜨리면 차례로 울려요. −/+(Z/X)로 옥타브.
- 진짜 악기 소리는 음마다 계산해 두었다가 쳐요. 코드 줄을 열면 그 코드들의 음을 쉬는 틈에 미리 계산하고, 스트럼은 줄 소리를 먼저 준비한 뒤 한 시각에서 고르게 긁어서 처음 치는 코드도 간격이 벌어지지 않아요.

### 입력
- **컴퓨터 건반**(M): A~K가 흰 건반, W·E·T·Y·U·O·P가 검은 건반, Z/X 옥타브, C/V 세기. 녹음 준비한 트랙(없으면 고른 트랙)으로 가요.
- **컴퓨터 키보드로 드럼**: 드럼 트랙을 고르고 M을 켜면 어느 화면에서나 글자 키가 드럼 패드예요. 기본(왼손 4×4)은 Z 킥 · C 스네어 · V 클랩 · S · F · W 탐 · D 닫힌 햇 · E 열린 햇 · 2 크래시 · 4 라이드이고, 패드 화면의 키 지정으로 바꾼 글자를 따라요. Shift를 누른 채 치면 노트 리피트, 상태 줄에 ⌨ 드럼 · 글자 키가 보여요. 루프 패드 트랙도 패드에 적힌 글자로 쳐요.
- **패드 글자 키**: 패드 화면(P)에서 패드마다 정한 글자로 쳐요. Shift를 누른 채 치면 노트 리피트.
- **MIDI 장치**: 상태 줄의 MIDI 단추(연결하면 장치 이름)를 누르면 **MIDI 장치 창**이 열려요 (아래 'MIDI 건반'). 크롬·엣지에서 돼요 (Claude 안에서는 브라우저가 막을 수 있어요).
- **MIDI 매핑**: 컨트롤 바의 MIDI를 켜고 노브·페이더를 누른 뒤 장치의 손잡이를 돌리면 이어져요. Delete로 끊어요. 끝없이 도는 노브(엔코더)도 돌린 만큼 조금씩 바뀌어요.

### MIDI 건반 (M-VAVE SMK-25 mini · Akai MPK mini MK3 등)
컴퓨터(맥·윈도우)의 크롬이나 엣지에서 웹사이트를 열고 건반을 USB-C 선으로 꽂으면 바로 연결돼요. 처음 열 때 브라우저가 MIDI 권한을 물으면 허용해 주세요. 상태 줄의 단추에 장치 이름이 보이고, 누르면 **MIDI 장치 창**에 건반 그림이 나와서 누르고 돌리는 대로 따라 움직여요.

| 장치 | 하는 일 |
|---|---|
| 건반 25개 | 녹음 준비한 트랙(없으면 고른 트랙)을 **누른 세기(키압)대로** 쳐요. 창의 건반이 세기만큼 차올라요 |
| 터치 감도 | 가볍게(살살 눌러도 크게) · 보통 · 무겁게(세게 눌러야 크게) · 고정. 작은 건반이 너무 여리게 나오면 가볍게 |
| 패드 8개 | 10번 채널(기본)의 음은 **드럼 트랙**으로 가요: 녹음 준비한 드럼 → 고른 드럼 → 첫 드럼 머신. 연주 화면의 드럼 세트도 번쩍여요. 패드 채널이 다르면 **패드 알아보기** |
| 건반으로 드럼 | 드럼 · 루프 패드 트랙을 고르거나 ● 녹음 준비하면 컴퓨터 키보드의 글자 키처럼 **건반 하나가 패드 하나**예요. 맨 왼쪽 C(25건반의 처음 옥타브는 C2)부터 반음씩 패드 1~16: C 킥 · D 스네어 · D# 클랩 · F · G · A 탐 · F# 닫힌 햇 · A# 열린 햇, 위 옥타브의 C# 크래시 · D# 라이드 (GM 배치와 같은 순서, C# · G# · B와 위 C · D는 킷마다 사이드 스틱 · 페달 햇 · 벨 · 탬버린 등). 그 위 E~B는 햇 · 탐을 한 번 더 쳐서 25건반 전체가 드럼이고, 두 옥타브마다 되풀이해요. 창의 **드럼 건반**에서 C1부터(GM)로 바꿀 수 있고, 건반 그림에 건반마다 드럼 이름이 적혀요. 패드는 늘 GM 자리(C1~D#2) 그대로예요 |
| 건반으로 코드 | 패드 화면에서 기타 · 베이스 · 현악의 **코드** 화면이나 건반 악기의 **코드 패드**를 열면 건반이 화음을 쳐요: 누른 음이 근음인 화음. 코드 줄은 아래 옥타브 다운 · 위 옥타브 업 스트럼, 코드 패드는 아래 옥타브 키 안의 화음 · 위 옥타브 세컨더리 도미넌트 (아래 '악기별 연주 화면' · '주요 화음 바로 쓰기'). 지판 · 건반 화면이나 다른 화면에서는 한 음씩 |
| 노브 8개 | **노브 알아보기**를 누르고 1번부터 차례로 오른쪽으로 돌리면 이어져요. 1 밝기 · 2 길이 · 3 두께 · 4 드라이브 · 5 공간 · 6 세기 반응 · 7 음량 · 8 트랙 볼륨 (건반이 치는 트랙의 소리 다듬기 손잡이). 보통 노브와 끝없이 도는 노브(↻)를 알아서 가려요 |
| 피치 벤드 | 음높이를 ±2반음(기본) 또는 ±1옥타브 올리고 내려요. 신스·현악·관악은 물론 피아노·기타 같은 진짜 악기도 휘어요 |
| 모드 | 올리면 비브라토(떨림)가 깊어져요 |
| 누르는 힘 (애프터터치) | 장치가 보내면 누른 채 더 세게 누를 때 비브라토가 깊어져요 (끌 수도 있어요). 창에 막대로 보여요 |
| 서스테인 | 누르고 있는 동안 건반에서 손을 떼도 소리가 이어져요 |
| 옥타브 · 아르페지에이터 · 코드 단추 | 건반 쪽에서 처리해서 그대로 들어와요 |

- 패드와 노브의 번호는 장치 설정(M-VAVE 편집 앱 등)에 따라 달라서 알아보기로 맞춰요 (MPK mini MK3는 아래처럼 미리 맞춰 두었어요). 패드가 건반과 같은 채널이면 갈라 줄 수 없어서, 편집 앱에서 패드 채널을 10번으로 바꾸라고 알려 줘요. 알아본 노브는 **장치마다 따로** 남아서 건반을 바꿔 꽂아도 섞이지 않아요. 설정은 이 브라우저에 남아요.
- 녹음하면 터치 감도를 거친 세기 그대로 클립에 남아요. 피치 벤드 · 모드 · 누르는 힘은 연주할 때만 쓰고 클립에는 남지 않아요.
- 블루투스로 쓰려면 컴퓨터의 블루투스·MIDI 설정(맥: Audio MIDI 설정 › 블루투스 구성)에서 먼저 연결한 뒤 창의 **다시 찾기**를 눌러요. USB-C 선이 가장 확실해요.
- **아이패드·아이폰**: 브라우저(사파리·크롬 모두)가 MIDI 장치를 지원하지 않아서 이 웹사이트로는 연결할 수 없어요. 컴퓨터에서 쓰거나, Web MIDI를 넣어 주는 브라우저 앱(예: Web MIDI Browser)으로 열어 보세요.

#### 연주 화면에서 MIDI 건반 = 손가락 · 컴퓨터 키보드
패드 화면에 그 트랙의 연주 화면이 보이면, MIDI 건반도 그 화면을 거쳐 쳐요. 화면에서 켜 둔 것(코드 · 스케일 · 자리 …)이 그대로 적용되고, 화면도 따라 움직여요 (누른 건반 · 줄 · 음판이 밝아지거나 떨려요). MIDI 장치 창의 건반 그림에 건반마다 그 화면이 칠 것이 적혀요.

| 연주 화면 | MIDI 건반 |
|---|---|
| 건반 (피아노) | 누른 음. **코드**를 켜면 한 건반으로 그 음의 3화음 (D → Dm) |
| 스케일 | 키 밖의 음은 가까운 키 안의 음으로 (같이 가까우면 아래로). 코드를 켜면 그 음의 3화음 |
| 코드 패드 | 누른 음이 근음인 화음: 아래 옥타브 위 줄 · 위 옥타브 세컨더리 도미넌트 |
| 기타 · 베이스 · 현악 코드 줄 | 누른 음의 코드: 아래 옥타브 다운 · 위 옥타브 업 스트럼 (베이스는 근음 · 옥타브, 현악은 누르는 동안) |
| 지판 | 지금 보이는 자리에서 그 음을 짚어 뜯어요 (손을 떼도 울려요, 현악은 누르는 동안 켜요) |
| 하프 · 가야금 | 그 음의 줄 (줄에 없는 음은 가까운 줄) |
| 마림바 · 비브라폰 · 종 · 스틸 드럼 | 그 음의 음판 (손을 떼도 울려요) |
| 칼림바 | 키 안의 건으로 (키 밖의 음은 가까운 건) |
| 드럼 세트 · 패드 · 루프 패드 | 건반 하나가 패드 하나 (맨 왼쪽 C = 패드 1). 패드 화면의 노트 리피트를 켜면 MIDI도 반복 |

- 패드 화면이 아니거나 다른 트랙을 치면 그 트랙에 누른 음 그대로 가요 (컴퓨터 건반 M과 같아요).
- **클립 칸의 코드 넣기**: 코드 탭을 열어 두면 MIDI 건반을 누를 때마다 그 음이 근음인 화음을 넣을 자리에 넣고 다음 자리로 넘어가요 (아래 옥타브 키 안의 화음 · 위 옥타브 세컨더리 도미넌트). 탭의 **MIDI 건반으로 넣기**로 끄고 켜요. 패드 화면이 보이면 건반은 그 화면을 쳐요.

#### Akai MPK mini MK3
꽂으면 이름(MPK mini 3)으로 알아보고, 알아보기 없이 바로 써요. MPK mini Play MK3도 같아요. MIDI 장치 창에 장치 이름표와 쓰는 법이 보여요.

| 장치 | 하는 일 |
|---|---|
| 건반 25개 | 누른 세기대로 쳐요 (위의 터치 감도도 그대로). 드럼 · 루프 패드 트랙을 고르면 컴퓨터 키보드의 글자 키와 같은 역할: 맨 왼쪽 건반(C2)이 패드 1(킥), 그다음 건반부터 패드 2 · 3 … 16 |
| 패드 8개 × A·B 뱅크 | 10번 채널의 음은 드럼 트랙으로 가요. 뱅크 A(36~43) = 드럼 패드 1~8, 뱅크 B(44~51) = 패드 9~16. 창의 패드 그림도 장치처럼 1~4가 아래 줄이고, 치는 뱅크에 따라 칸 번호(1~8 · 9~16)가 바뀌어요 |
| 노브 K1~K8 | 기본 설정(CC 70~77)에 미리 이어 두었어요: K1 밝기 · K2 길이 · K3 두께 · K4 드라이브 · K5 공간 · K6 세기 반응 · K7 음량 · K8 트랙 볼륨. 편집 앱에서 노브를 상대값(Relative)으로 바꿔도 처음 돌릴 때 알아내서 값이 튀지 않아요 |
| 조이스틱 | 좌우 = 피치 벤드, 위 = 모드(비브라토) |
| 서스테인 페달 단자 | 서스테인 |
| 아르페지에이터 · 노트 리피트 · 옥타브 · Full Level | 건반 쪽에서 처리해서 그대로 들어와요. 빠르기는 건반의 TAP TEMPO를 따르고(이 앱은 MIDI 클록을 보내지 않아요), 건반의 클록 설정은 내부(Internal)로 두세요 |

- MPK mini 3 Program Editor나 다른 프로그램(PROG)으로 노브 번호를 바꿨다면 **노브 알아보기**로 다시 맞춰요. 알아본 것이 미리 이은 것보다 먼저고, **지우기**를 누르면 CC 70~77로 돌아가요.
- 패드를 CC · 프로그램 체인지 모드로 바꾸면 드럼으로 가지 않아요. 음(NOTE) 모드로 두세요.

### 파일로 저장 · 열기
프로젝트는 고칠 때마다 이 브라우저(Claude 판은 내 계정)에 자동으로 저장되고, 따로 **컴퓨터의 파일**로도 저장할 수 있어요. 브라우저 데이터를 지워도 파일은 남고, 그 파일을 다른 컴퓨터나 브라우저에서 열 수 있어요.

| | 크롬 · 엣지 (컴퓨터) | 사파리 · 파이어폭스 · 아이패드 · Claude 판 |
|---|---|---|
| 저장 | **파일에 저장** (Ctrl+S): 처음에는 저장할 자리와 이름을 묻고, 그다음부터는 같은 파일에 바로 덮어써요 | **프로젝트 파일 받기**: 파일을 내려받아요 (아이패드는 공유 화면 › "파일에 저장"). Ctrl+S는 이 브라우저에 바로 저장해요 |
| 다른 파일로 | **다른 파일로 저장…** (Ctrl+Shift+S): 새 파일과 이어지고 프로젝트 이름도 그 파일 이름으로 바뀌어요. 원래 파일은 마지막으로 저장한 그대로 남아요 | 프로젝트 파일 받기 (Ctrl+Shift+S) |
| 열기 | **파일 열기…** (Ctrl+O): 연 파일과 이어져서 Ctrl+S가 그 파일에 저장해요. 화면에 끌어다 놓아도 열려요 | **파일 열기…** (Ctrl+O): 고른 파일을 프로젝트로 열어요 |

- 상태 줄에 이어진 파일 이름과 **저장됨 / 저장 안 함**이 보여요. 누르면 파일에 저장 · 다른 파일로 저장 · 파일 열기 · 파일과 연결 끊기 메뉴가 열려요. 아직 파일이 없으면 **파일로 저장** 버튼이 보여요. 좁은 화면에서는 저장 상태만 보여요.
- 되돌리기로 저장한 때와 같은 상태로 돌아가면 다시 '저장됨'이 돼요.
- 프로젝트와 파일의 연결은 그 브라우저에 기억해요. 앱을 다시 열어도 Ctrl+S가 같은 파일에 저장해요 (브라우저가 파일을 고쳐도 되는지 한 번 물을 수 있어요).
- 이어진 파일을 다시 열 때, 이 브라우저에 그 파일에 저장하지 않은 내용이 있으면 **파일 내용으로 열기**와 **바뀐 내용으로 열기** 중에서 골라요.
- 이 브라우저에 있는 프로젝트를 덮어쓰지 않아요. 같은 프로젝트에서 나온 파일이라도 그 프로젝트와 이어져 있지 않으면 새 프로젝트로 열어요.
- 파일(`.ullim.json`)에는 가져온 오디오·녹음도 함께 담겨요. 예전에 '프로젝트 파일 내보내기'로 받은 파일도 그대로 열려요.
- 메뉴의 **사본 만들기…**는 이 브라우저 안에 이름을 바꾼 사본을 만들어요 (예전의 '다른 이름으로 저장'). **이 브라우저의 프로젝트…**(Claude 판은 Claude 계정의 프로젝트…)는 브라우저 칸의 프로젝트 목록을 열고, 파일과 이어진 프로젝트에는 파일 이름이 함께 보여요.
- 새 프로젝트 창과 디자인 B의 5 내보내기 단계(C의 내보내기 탭)에도 파일 열기 · 파일에 저장이 있어요.

### 내보내기 · 가져오기
- **오디오 내보내기**: 어레인지먼트 전체, 루프 구간, 세션 씬 하나 중에서 골라 WAV(16/24/32비트 float, 44.1/48 kHz)로 받아요. 트랙별 스템도 함께 받을 수 있어요(ZIP). 노멀라이즈 선택.
- **MIDI 파일 내보내기**: 어레인지먼트의 MIDI 트랙 전체 (없으면 고른 클립).
- **프로젝트 파일**(`.ullim.json`): 위의 '파일로 저장 · 열기'를 봐 주세요.
- 오디오 파일은 브라우저 버튼이나 화면에 끌어다 놓아 가져와요. 파일 이름에 `120bpm`처럼 템포가 있거나 길이가 마디에 맞으면 루프로 알아보고 워프를 켜요.
- Claude 안에서는 WAV·MIDI를 ZIP으로 묶어서 내려받아요 (Claude가 받을 수 있는 파일 형식 때문이에요).

맥에서는 Ctrl 대신 ⌘예요. 앱 안의 메뉴 › 도움말에서도 볼 수 있어요.

## Live 12와 다른 점

- 소리는 대부분 Web Audio로 합성해요. 내장 샘플(브레이크 루프, 보컬 찹, 효과음, LP 잡음 등)도 처음 쓸 때 만들어져요. 피아노 · 현악 · 관악 · 오르간 · 기타 · 베이스 · 말렛 · 밴드 드럼처럼 실제 악기는 무료로 공개된 녹음 샘플(모두 합쳐 약 15 MB, 악기 · 키트마다 따로)을 처음 쓸 때 받아요 (아래 '소리 출처').
- 워프는 Beats(16분음표로 썰어 다시 배치), Tones/Texture(그레인), Re-Pitch(속도와 음높이 함께)로 흉내 내요. 워프 마커는 없어요.
- 그룹 트랙, 랙, 클립 엔벌로프, 크로스페이더, 프리즈, 템포 자동화, Max for Live는 없어요.
- 루프 패드와 패드 화면은 Live에 없는 MPC식 기능이에요 (Live라면 Drum Rack에 Simpler 슬라이스를 담아 Push로 치는 것에 가까워요).
- 장르 템플릿, 드럼 클립의 스텝 시퀀서, 씬으로 곡 만들기도 Live에는 없어요 (Live에서는 템플릿 세트를 만들어 두고, 세션 녹음으로 어레인지먼트를 채워요).
- VST 플러그인은 쓸 수 없어요.

## 웹사이트로 쓰기

- 주소: https://jinnsei99.github.io/jinnsei/ullim/ (같은 사이트 맨 위 `/jinnsei/`는 캠퍼스 가계부예요).
- **앱으로 설치**: 크롬·엣지는 주소창의 설치 아이콘이나 메뉴 › 앱으로 설치하기, 아이폰·아이패드는 사파리의 공유 › 홈 화면에 추가. 설치하면 주소창 없이 창 하나로 열려요.
- **인터넷 없이**: 처음 열 때 서비스 워커(`sw.js`)가 앱 파일을 모두 받아 둬요. 그다음부터는 비행기 모드에서도 열리고 소리가 나요 (소리는 대부분 브라우저에서 합성하고, 녹음 샘플은 한 번 쓰면 받아 둬요). 인터넷이 되면 언제나 새 파일을 먼저 받아서, 고친 내용이 바로 보여요.
- 사이트의 프로젝트는 그 브라우저에 저장돼요. 컴퓨터에 파일로도 저장할 수 있어요 (크롬·엣지는 Ctrl+S, 다른 브라우저는 메뉴 › 프로젝트 파일 받기).
