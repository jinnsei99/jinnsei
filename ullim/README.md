# 울림 스튜디오

Ableton Live 12처럼 쓰는 음악 작업 앱이에요. 브라우저에서 바로 돌아가고 빌드 과정이 없어요.

- Claude에서 바로 쓰기: https://claude.ai/artifact/Thx9zzCx7voyvXnDY7V5rN (프로젝트가 내 Claude 계정에 저장돼요)
- 이 폴더의 `index.html`을 크롬이나 엣지로 열어도 똑같이 쓸 수 있어요. 인터넷이 없어도 소리가 나요 (글꼴만 기본 글꼴로 바뀌어요).

처음 열면 데모 곡 **새벽 네 시** (122 BPM, A 마이너)가 열려 있어요. 세션 뷰에서 클립의 ▶를 하나씩 눌러 보세요.

## 화면

| 칸 | 하는 일 |
|---|---|
| 컨트롤 바 (위) | 템포·탭 템포·박자표, 메트로놈, 런치 퀀타이즈, 재생·정지·녹음·세션 녹음·MIDI 캡처, 재생 위치, 어레인지먼트로 돌아가기, 루프, 스윙, 프로젝트 키, 그리기·자동화 모드, 컴퓨터 건반, MIDI 매핑 |
| 브라우저 (왼쪽) | 사운드, 드럼 키트, 악기, 오디오·MIDI 이펙트, 클립 템플릿, 샘플, 가져온 오디오, 저장된 프로젝트 |
| 세션 / 어레인지먼트 (가운데) | Tab으로 오가요 |

화면 폭이 860px보다 좁으면 (휴대폰, Claude 옆 창) 아래 탭으로 세션 · 어레인지 · 편집 · 브라우저를 한 칸씩 봐요.

## 기능

### 세션 뷰
- 트랙마다 클립 칸이 있고, 가로 한 줄이 **씬**이에요. 클립의 ▶는 클립 하나, 오른쪽 열의 ▶는 씬 전체를 띄워요. 빈 칸인 트랙은 멈춰요.
- **런치 퀀타이즈**(없음~8마디)에 맞춰 다음 경계에서 시작해요. 기다리는 클립은 깜빡여요. 클립마다 퀀타이즈를 따로 정할 수 있어요.
- 런치 방식 Trigger · Gate · Toggle, **레가토**(앞 클립 위치에서 이어 받기), **팔로우 액션**(정해 둔 시간이 지나면 다음·이전·처음·마지막·아무거나·다른 것·다시·정지, A/B 확률).
- 씬 이름·씬 템포, 씬 넣기·복제·지우기, 재생 중인 클립으로 새 씬 만들기.
- 클립을 끌어 옮기고 Alt를 누르고 끌면 복사해요. 빈 칸을 두 번 누르면 빈 MIDI 클립이 생겨요.
- 아래 **믹서**: 센드 A/B…, 팬, 볼륨 페이더와 스테레오 미터(피크 홀드), 트랙 켜기/끄기, 솔로(Ctrl을 누르면 여러 개), 녹음 준비.
- 세션 클립을 띄운 트랙은 어레인지먼트를 잠시 쉬어요. **어레인지먼트로 돌아가기** 버튼이 켜지면 눌러서 되돌려요 (Live와 같은 동작).

### 어레인지먼트 뷰
- 눈금자를 눌러 시작 위치를 정하고, 위쪽 띠에서 **루프 구간**을 끌어 정해요. 재생 중에 루프를 켜고 끄거나 옮겨도 위치가 끊기지 않아요.
- 클립 옮기기(다른 트랙으로도), 양 끝 끌어 자르기·늘이기(루프 클립은 반복해서 늘어나요), Alt로 복사, Ctrl+D 복제, Ctrl+E 나누기, Ctrl+J 합치기, Ctrl+L 선택 구간을 루프로.
- 빈 MIDI 레인을 두 번 누르면 1마디 클립이 생겨요. 세션 클립이나 브라우저 항목을 끌어다 놓아도 돼요.
- **자동화 모드**(A): 레인마다 볼륨·팬·센드·장치 파라미터 중 하나를 골라 점을 찍고 끌어요. 점을 두 번 누르면 지워요. 그리기 모드(B)에서는 끄는 대로 격자마다 점을 찍어요. 재생하면 노브와 페이더가 자동화를 따라 움직여요.
- 따라가기, 확대(+/−, Ctrl+휠), 전체 보기, 스냅(Ctrl+4, Alt로 잠깐 반대).

### 클립 뷰
- **피아노 롤**: 두 번 눌러 음 넣기·지우기, 끌어 옮기기·길이 바꾸기, 상자로 여러 개 고르기, 화살표로 옮기기(Shift: 옥타브), 복사·붙여넣기, 퀀타이즈(Ctrl+U), 음 켜기/끄기(0), 벨로시티 줄, 건반 눌러 미리 듣기.
- 그리기 모드(B)로 끌면 격자마다 음을 찍어요. 격자 자동/고정, 셋잇단(Ctrl+3), 폴드(쓴 음만·스케일 음만).
- **스케일**: 프로젝트 키(컨트롤 바)나 클립만의 키로 스케일 음 줄을 밝게 보여 줘요. 드럼 트랙은 패드 이름으로 줄을 보여 줘요.
- 편집 단추: ×2, ÷2, 루프 복제, 거꾸로, 위아래 뒤집기, 레가토, 퀀타이즈, 스케일에 맞추기, 옥타브 옮기기.
- **MIDI 도구** (Live 12의 Generate / Transform):
  - 만들기: 리듬(유클리드), 씨앗(스케일 안 무작위 멜로디), 코드 쌓기(진행·음 수·전위·펼침), 모양(사인·오르막·내리막·삼각·랜덤 워크)
  - 바꾸기: 아르페지오, 스트럼, 퀀타이즈(양 조절), 휴머나이즈, 세기 모양, 재조합(섞기·돌리기·뒤집기·거울), 길이(레가토·고정·비율·스타카토), 잇기(스케일 음으로 사이 채우기), 스케일 이동
- **오디오 클립**: 워프 켜기/끄기, 워프 모드 Beats · Tones · Texture · Re-Pitch, 원래 BPM(×2 ÷2), 음높이, 게인, 거꾸로, 루프 구간.

### 장치
| 종류 | 장치 |
|---|---|
| 악기 | Poly Synth (오실레이터 2개·노이즈·LP12/LP24/HP/BP 필터·필터/음량 엔벌로프·LFO·모노와 글라이드), FM Synth (오퍼레이터 3개, 연결 방식 3가지), Drum Machine (패드 16개, 합성 드럼 16종 또는 샘플, 초크 그룹), Sampler (Classic · 1-Shot · Slice, 루프, 필터) |
| 오디오 이펙트 | EQ Six (그래프에서 끄는 6밴드 + 스펙트럼), Compressor, Limiter, Reverb, Delay (핑퐁, 박자 동기), Auto Filter (LFO 박자 동기), Saturator (Bit Crush 포함), Chorus/Flanger/Vibrato, Phaser, Utility, Ducker (사이드체인 펌핑), Spectrum |
| MIDI 이펙트 | Arpeggiator, Chord (스케일 도수 모드), Scale, Velocity |

- 노브는 위아래로 끌어 바꾸고(Shift: 미세), 두 번 누르면 기본값이에요. 제목을 끌어 순서를 바꾸고, ▾ 메뉴에서 프리셋을 골라요.
- 엔벌로프 그래프의 점, EQ 그래프의 점(휠: Q), 샘플러 파형의 시작·끝·루프 표시를 바로 끌 수 있어요.

### 녹음
- **MIDI 녹음**: 트랙의 ●(녹음 준비)를 켜고 F9 또는 ● 버튼. 컴퓨터 건반이나 MIDI 건반 연주가 어레인지먼트 클립이 돼요.
- **세션 녹음**: 빈 칸에 새 클립을 녹음하고, 다시 누르면 마디에 맞춰 길이를 정하고 루프로 돌려요. 재생 중인 클립에는 겹쳐 녹음해요.
- **세션 → 어레인지먼트**: 어레인지먼트 녹음을 켠 채로 세션 클립과 씬을 띄우면, 띄운 그대로 어레인지먼트에 적혀요.
- **MIDI 캡처**: 녹음을 켜지 않고 친 연주를 버튼 하나로 클립으로 건져요.
- **오디오 녹음**: 오디오 트랙을 녹음 준비하고 녹음하면 마이크 소리가 클립이 돼요. Claude 안에서는 마이크를 쓸 수 없어서, 이 기능은 파일로 연 `index.html`에서 돼요.

### 입력
- **컴퓨터 건반**(M): A~K가 흰 건반, W·E·T·Y·U·O·P가 검은 건반, Z/X 옥타브, C/V 세기. 녹음 준비한 트랙(없으면 고른 트랙)으로 가요.
- **MIDI 장치**: 상태 줄의 "MIDI 연결". 크롬·엣지에서 돼요 (Claude 안에서는 브라우저가 막을 수 있어요).
- **MIDI 매핑**: 컨트롤 바의 MIDI를 켜고 노브·페이더를 누른 뒤 장치의 손잡이를 돌리면 이어져요. Delete로 끊어요.

### 내보내기 · 가져오기
- **오디오 내보내기**: 어레인지먼트 전체, 루프 구간, 세션 씬 하나 중에서 골라 WAV(16/24/32비트 float, 44.1/48 kHz)로 받아요. 트랙별 스템도 함께 받을 수 있어요(ZIP). 노멀라이즈 선택.
- **MIDI 파일 내보내기**: 어레인지먼트의 MIDI 트랙 전체 (없으면 고른 클립).
- **프로젝트 파일**(`.ullim.json`): 가져온 오디오까지 담아서 다른 기기로 옮겨요.
- 오디오 파일은 브라우저 버튼이나 화면에 끌어다 놓아 가져와요. 파일 이름에 `120bpm`처럼 템포가 있거나 길이가 마디에 맞으면 루프로 알아보고 워프를 켜요.
- Claude 안에서는 WAV·MIDI를 ZIP으로 묶어서 내려받아요 (Claude가 받을 수 있는 파일 형식 때문이에요).

## Live 12와 다른 점

- 소리는 모두 Web Audio로 합성해요. 내장 샘플(브레이크 루프, 보컬 찹, 효과음 등)도 처음 쓸 때 만들어져서 내려받을 파일이 없어요.
- 워프는 Beats(16분음표로 썰어 다시 배치), Tones/Texture(그레인), Re-Pitch(속도와 음높이 함께)로 흉내 내요. 워프 마커는 없어요.
- 그룹 트랙, 랙, 클립 엔벌로프, 크로스페이더, 프리즈, 템포 자동화, Max for Live는 없어요.
- VST 플러그인은 쓸 수 없어요.

## 데이터 저장 방식

| 여는 곳 | 프로젝트 | 가져온 오디오·녹음 |
|---|---|---|
| Claude 아티팩트 | 내 Claude 계정의 비공개 영역 (`data/users/<내 id>/`). 기기를 바꿔도 이어서 열려요. 큰 프로젝트는 여러 문서로 나눠 저장해요. | 이 브라우저 (IndexedDB) |
| 그 밖의 브라우저 (파일로 열기 등) | 이 브라우저 (IndexedDB `ullim`) | 이 브라우저 |

- 바꿀 때마다 1.5초 뒤 자동으로 저장해요. Ctrl+S는 바로 저장해요.
- 다른 기기에서 열었는데 가져온 오디오가 없으면, 같은 파일을 다시 가져오거나 프로젝트 파일로 옮겨 주세요.
- 화면 설정(보이는 칸, 아래 칸 높이, 마지막 프로젝트 등)은 브라우저의 `localStorage`(`ullim:prefs:v1`)에 둬요.

## 기술 메모

- 스케줄러는 Web Worker 타이머로 25ms마다 깨어나 120ms 앞까지 음을 예약해요. 이미 예약한 구간 안에서 클립을 바꾸면 그 뒤를 지우고 다시 예약해서 늦지 않게 바꿔요.
- 엔벌로프는 `setTargetAtTime`만 써서 중간에 음을 끊어도 틱 소리가 나지 않아요.
- 내보내기는 같은 엔진을 `OfflineAudioContext`에서 돌려요. 스템은 채널을 트랙 수만큼 늘린 렌더 한 번으로 만들어요.
