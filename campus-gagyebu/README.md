# 캠퍼스 가계부

대학생을 위한 가계부 웹앱이에요. 빌드 과정 없이 `index.html` 파일 하나로 돌아가요.

- 휴대폰 앱처럼 쓰기: https://jinnsei99.github.io/jinnsei/ (GitHub Pages, 아래 '스마트폰에서 쓰기' 참고)
- Claude에서 바로 쓰기: https://claude.ai/artifact/3Yv4pTRocx1oRqbXAKtHg4
- 이 폴더의 `index.html`을 브라우저로 열어도 똑같이 쓸 수 있어요.

## 기능

- **오늘 쓸 수 있는 돈**: 남은 예산을 남은 날수로 나눠 매일 다시 계산해요. 이번 달에 아직 나가지 않은 고정지출은 미리 빼요.
- **한 달 시작일**: 설정에서 한 달이 시작하는 날(1~28일)을 고를 수 있어요. 25일로 하면 9/25~10/24가 한 달이 되고, 예산·달력·통계·무지출·이번 달 CSV가 모두 이 기간을 따라요.
- **이번 달만 남은 돈으로 맞추기**: 달 중간에 시작했거나 계획이 틀어졌을 때 지금 남은 돈을 넣으면, 그날부터 그 돈으로 나눠 계산해요. 다음 달부터는 월 예산으로 돌아가요. 처음 시작할 때도 고를 수 있어요.
- **빠른 기록**: 금액, 카테고리, 날짜, 메모를 적어요. 같은 내역을 두 번 넘게 적으면 '자주 쓰는 기록' 버튼으로 한 번에 채울 수 있어요.
  - **저장하고 하나 더**: 창을 닫지 않고 바로 다음 기록을 적어요. 구분과 날짜는 그대로 두고, 방금 저장한 내용을 위에 보여 줘요.
  - 고른 날짜는 10분 동안 기억해요. 오늘이 아닌 날이면 저장 버튼에 날짜가 나와요(예: '어제 날짜로 저장').
- **저축**: 지출·수입과 따로 적어요. 예산과 무지출 계산에는 넣지 않고, 남은 돈(합계)에서만 빼요.
- **환불**: 지출을 적을 때 '환불'을 켜면 고른 카테고리의 지출에서 그만큼 빼요. 수입으로 잡히지 않아요.
- **N빵**: 다 같이 낸 금액과 인원을 넣으면 내 몫만 기록해요.
- **알바 시급 계산**: 시급 × 일한 시간으로 수입을 채워요. 기본값은 2026년 최저시급 10,320원이에요.
- **무지출 챌린지**: 고정지출을 빼고 한 푼도 안 쓴 날과 연속 기록을 세요. 자동으로 적힌 고정 항목뿐 아니라 직접 적은 주거·통신, 구독 지출도 빼요.
- **고정 수입·지출·저축**: 용돈, 휴대폰 요금, 적금처럼 매달 같은 날 오가는 돈을 등록하면 그날 자동으로 기록해요. 방학처럼 잠깐 쉴 때는 '자동 기록'을 끄면 되고, 다시 켜도 쉬었던 달은 채우지 않아요.
- **내역·달력**: 카테고리 필터와 메모 검색을 지원하고, 달력은 많이 쓴 날일수록 진하게 칠해요.
  - 검색은 전체 기간에서 찾고, '이 달에서만 찾기'로 좁힐 수 있어요.
  - 필터를 쓰는 동안에는 위에 조건과 '필터 지우기'가 보여요. 내역 탭을 다시 누르면 필터 없이 열려요.
- **통계**: 카테고리별 지출, 날마다 쓴 돈(하루 예산선 포함), 요일별 평균, 최근 6개월 추이를 보여 줘요.
- **카테고리 예산**: 정해 둔 금액을 넘으면 경고해요.
- **내보내기·백업**: 엑셀용 CSV와 백업(JSON) 파일을 받고, 백업 파일을 다시 불러올 수 있어요.
  - 불러올 때 **합치기**(지금 기록은 두고 백업에만 있는 기록과 고정 항목을 더함)와 **바꾸기**(백업으로 통째로 바꿈) 중에 골라요. Claude 링크와 휴대폰 앱의 기록을 한곳에 모을 때 합치기를 쓰세요.
  - 이 기기에 저장하는 모드에서는 기록이 20건을 넘으면 30일마다 홈에서 백업을 권해요. '나중에'를 누르면 일주일 뒤에 다시 알려요.
- **테마**: 설정 > 테마에서 6가지 중에 고를 수 있어요. 고른 테마는 설정에 저장돼서 다른 기기에도 똑같이 적용돼요.
  - **기존**: 모눈 노트 배경에 중요한 숫자만 형광펜으로 칠해요.
  - **엑셀**: 스프레드시트 모양을 따라 했어요.
    - 화면 틀: 초록 제목 표시줄, 열 머리글(A, B, C…)과 행 번호, 셀 격자 배경. 세로가 짧은 휴대폰(높이 720px 이하)에서는 제목 표시줄을 접어 내용이 더 보여요.
    - 아래쪽: 시트 탭, 그리고 개수·합계가 나오는 상태 표시줄
    - 숫자 표시: 오늘 쓸 수 있는 돈은 선택된 셀처럼 보이고, 예산 막대는 데이터 막대예요.
    - 상태 표시: 좋음·보통·나쁨 셀 스타일
    - 달력: 녹색-노랑-빨강 색조
  - **영수증**: 지그재그로 뜯긴 감열지 한 장이에요. 고정폭 글씨(나눔고딕코딩), 점선, 프린터로 찍은 듯한 막대를 쓰고 이모지는 흑백이에요. 예산을 넘긴 숫자만 빨간색으로 찍혀요.
  - **칠판**: 초록 칠판에 분필 손글씨(개구체)로 써요. 오늘 쓸 수 있는 돈에는 분필 동그라미를 치고, 메뉴는 나무 분필받이 모양이에요. 라이트·다크 모드 모두 칠판으로 보여요.
  - **다꾸**: 다이어리 속지의 점 모눈 위에 마스킹테이프와 파스텔 스티커를 붙인 느낌이에요. 제목 글씨는 감자꽃체예요.
  - **흑백**: 색 없이 검정과 흰색만 써서 또렷하게 보여요. 숫자는 반전 상자로 강조해요. 화면이 잘 안 보일 때 쓰기 좋아요.
  - 칠판을 뺀 테마는 라이트·다크 모드를 따로 지원해요.

## 데이터 저장 방식

| 여는 곳 | 저장 위치 |
|---|---|
| Claude 아티팩트 | 내 Claude 계정의 비공개 영역(`data/users/<내 id>/`). 기기 간에 이어서 쓸 수 있고 다른 사람은 볼 수 없어요. |
| 그 밖의 브라우저 (파일로 열기, GitHub Pages 등) | 그 브라우저의 `localStorage` (`campus-gagyebu:v1` 키). 브라우저 데이터를 지우면 사라지니 가끔 백업 파일을 받아 두세요. |

문서 구조는 두 환경이 같아요.

- `settings`: 월 예산, 한 달 시작일(`startDay`), 이번 달만 맞춘 예산(`periodBudget`), 카테고리별 예산, 시급, 고정 항목 목록(`on: false`면 일시정지)
- `m-YYYY-MM`: 그달(달력 기준)의 기록. `tx` 아래에 기록 id를 키로 저장해요. 구분(`type`)은 `out`(지출), `in`(수입), `save`(저축)이고, 환불은 금액이 음수인 지출이에요.

## 스마트폰에서 쓰기

GitHub Pages 주소(https://jinnsei99.github.io/jinnsei/)를 휴대폰 브라우저로 열고 홈 화면에 추가하면, 아이콘을 눌러 앱처럼 전체 화면으로 쓸 수 있어요.

- **아이폰**: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)

한 번 열어 두면 인터넷이 없어도 앱이 열려요. 이 방식은 기록이 그 휴대폰에만 저장되니, 설정 > 데이터에서 가끔 백업 파일을 받아 두세요. 휴대폰에서 내보내기를 누르면 공유 창이 떠서 '파일에 저장'이나 메신저로 보낼 수 있어요.

휴대폰과 컴퓨터에서 같은 기록을 보고 싶다면 Claude 링크를 쓰세요. Claude 계정에 저장돼서 어느 기기에서든 이어서 쓸 수 있어요.

## 배포

`.github/workflows/campus-gagyebu-pages.yml`이 `main`에 이 폴더가 바뀔 때마다 GitHub Pages로 올려요. 처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꾼 뒤, Actions 탭에서 **캠퍼스 가계부 배포**를 실행해 주세요.

## 파일

- `index.html`: 앱 전체 (HTML·CSS·JS)
- `manifest.webmanifest`, `icons/`: 홈 화면 설치 정보와 아이콘
- `sw.js`: 오프라인에서도 열리게 하는 서비스 워커. 앱 파일을 바꾸면 안의 `CACHE` 이름 숫자를 올려 주세요.
